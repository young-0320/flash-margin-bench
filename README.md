## 한 줄 요약

플래시 메모리가 **불량인지 판정하는 대신, 여유(마진)가 얼마나 남았는지를 피코초 단위로 측정한다.**
PASS/FAIL이라는 1비트짜리 답 대신, 단위가 있는 연속적인 물리량(유효 윈도우 폭, ps)을 얻는다.

그리고 같은 벤치로 칩을 정격 내구의 1-3배까지 닳게 해 **무엇이 늙는지**를 쟀다. 타이밍 마진은 움직이지 않았고 소거 시간이
늘었다 — 그 곡선으로 **이력을 모르는 칩이 몇 번 쓰였는지를 측정 한 번으로 역산**하고, 정답을 숨긴 칩으로 검증했다.

## 방법 (3줄)

1. **위상 스윕** — FPGA의 MMCM 미세 위상 제어로 읽기 샘플 클럭을 **Δφ = 15.873ps** 간격으로 밀며, 각 위상에서 PRBS15 패턴을 N회(1회 = 2,048비트) 읽어 비트 에러를 센다 — 아래 게재 수치는 **N = 100**, 현행 실칩 표준은 **N = 112**(수정안 #2).
2. **욕조 곡선 → 폭** — 위상 대 BER 곡선의 양쪽 벽에서 판정 기준 **θ = 10⁻²** 와의 교점을 구해, 데이터가 올바르게 읽히는 **유효 윈도우 폭(ps)** 을 산출한다.
3. **측정을 먼저 의심한다** — 칩 없이 FPGA 단독 루프백으로 메커니즘을 물리 검증(G0)한 뒤 실칩에 들어가고, 같은 칩 5회 반복으로 측정 노이즈 플로어를 정량화(G4)한 다음에만 실칩 수치를 주장한다.

> 에러가 나기를 기다리는 것이 아니라, 측정 장비 쪽이 경계까지 다가간다. 그래서 스펙 안에서 멀쩡히 동작하는(모든 칸이 PASS인) 정상 칩에서도 실험이 성립한다.

## 측정 파라미터 근거

스윕 1회 = **위상 2,520스텝 × 100읽기 × 2,048비트 = 5.16억 비트**, 약 5분(25MHz 기준). 현행 실칩 설정(N=112·UART 921600)에서는 5.78억 비트를 **59초**에 뜬다. 스텝 수는 샘플 클럭 한 주기(UI)를 Δφ로 나눈 값이라 클럭마다 다르다 — 25MHz 2,520 / 45MHz 1,400 / 75MHz 840스텝.

**N = 100의 근거** — 파라미터는 감이 아니라 몬테카를로로 **사전 등록**했다(`host/analysis/monte_carlo_sweep_params.py`). 선택 규칙은 "폭 추정 편차 σ_width ≤ Δφ/2 를 만족하는 최소 N": 자 눈금(15.873ps)보다 통계 노이즈가 크면 낭비고, 훨씬 작아도 양자화에 묻혀 이득이 없다. N의 하한은 채택 θ가 아니라 **병행 기록 최저 θ(10⁻⁴)의 유효 조건**(`N·B·θ` 약 20 이상)이 정한다 → B = 2,048이면 N ≥ 98 → **N = 100**. (에러가 20개는 쌓여야 BER 추정의 상대오차가 ±22%로 실용선에 든다.)

**현행 실칩 표준은 N = 112다** (계약 수정안 #2, 2026-09-15 승인). 바꾼 이유는 통계가 아니라 **마모 실험과의 영역 정합**이다 — 112페이지 = 7섹터 = 마모 그룹 크기라 읽기 창이 마모군과 정확히 겹친다(`docs/spec/s1.wear_bench_spec.md` §2·§3). 위 사전 등록 규칙은 N = 112에서도 통과한다(σ_width = 0.16 / 0.34 / 1.35ps @θ=10⁻²/10⁻³/10⁻⁴, 규칙 한계 7.9ps). **G0 루프백은 100을 유지한다** — 칩 데이터가 아니라 자기 이력과 비교하는 경로이기 때문이다.

![위상당 읽기 횟수 N 선택](docs/results/plots/monte_carlo_n_selection.png)

![판정 기준 θ 선택](docs/results/plots/monte_carlo_theta_selection.png)

*가상의 욕조 곡선 위에서 "N회 읽기 → 경계 판정 → 폭 계산"을 수천 회 반복해, 폭 추정 편차를 N과 θ의 함수로 구한 것. 실측 전에 규칙을 문서로 고정했고(사전 등록), G0 체크리스트에 "실측 σⱼ로 재실행해 N=100 재확인" 절차까지 걸어 두었다.*

이 사전 등록이 결과를 지켰다 — θ = 10⁻⁴까지 통계적으로 유효하게 기록해 둔 덕분에, 아래 한계 절의 "θ 3값 폭 수렴(27ps)" 논증이 성립한다.

**시료**: W25Q64 — 다섯 번 산 34칩(등록 34 라벨) 중 31칩 신품 측정(FV 19 · JV 12, 3칩은 무응답). 마모 · 교정 · 블라인드는
**W25Q64FV** 로 했고, JV 는 신품 측정과 교정 밖 마모 2칩까지다. 들어온 칩은 전부 신품 상태로 먼저 재고(용도가 아니라 단계), 그 뒤
파일럿 · 종단 마모(교정) · 블라인드 · 온도로 갈랐다. 배정의 정본은 `docs/chip_registry.md`.
**아래 1)-3) 은 chip01 단일 개체**의 7월 게재분이고, 여러 칩의 결과는 4) 부터다.

## 결과

### 1) 실칩 클럭 사다리 — W25Q64 (chip01), 25 / 45 / 75MHz

| 클럭            | UI (1비트 시간) | width @ θ=10⁻²  | UI 대비 | 벽 폭             | 천장 BER | 2점 σⱼ (좌/우) |
| --------------- | --------------- | ------------------ | ------- | ----------------- | -------- | ---------------- |
| **25MHz** | 40,000ps        | **39,737ps** | 99.3%   | 약 302ps (19스텝)   | 0.2462   | 6.3 / 10.8ps     |
| 45MHz           | 22,222ps        | 21,898ps           | 98.5%   | 약 381ps (24스텝)   | 0.2462   | 9.0 / 10.8ps     |
| 75MHz           | 13,333ps        | 12,205ps           | 91.5%   | 약 1,175ps (74스텝) | 0.2462   | 13.0 / 16.0ps    |

세 클럭 모두 `valid=1` 완주, 체크 2(BER floor)·4(과분산 F)·5(프레이밍 슬립) PASS.

읽을 거리 두 가지:

- **벽 폭이 클럭과 함께 증가**(302 → 381 → 1,175ps)한다. 프로토콜 아티팩트라면 스텝 수가 클럭에 따라 이렇게 체계적으로 늘 수 없다 → 관측된 벽은 **채널 물리**(대역폭 제한형, ISI류 지연 퍼짐)다.
- **천장 BER 0.2462가 세 클럭에서 완전히 동일**하다. 클럭을 3배 올려도 취약 비트 집합의 비율이 불변 → 결정론적 패턴 의존성의 가장 강한 단일 증거(랜덤 지터 지배라면 0.5로 수렴해야 한다).

### 2) 반복성 (G4) — 25MHz × 5회, 재장착 없음

**width @ θ=10⁻² = 39,737.3 ± 0.61 ps** (상대 편차 0.0015%, min 39,736.6 / max 39,738.0)

- **타이밍 마진은 정격 내구의 2-3배까지 3σ(42ps) 안에서 움직이지 않았다**(chip01 30만 회 +15.5ps). 마모 전에 적어 둔 가설(H1)이

  배선 사건(chip07 +590ps), 그리고 chip07 의 초기 −59ps(사후 처리로 표시) · chip14 의 90k −43ps 였고, 단차 뒤에는 다시 움직이지 않았다

- **같은 무리 안에서도 늙는 속도가 약 3배까지 다르다** — 뒤의 역산이 점이 아니라 구간으로 답하는 이유다
- **닳지 않은 섹터는 그대로다.** 10만 회 뒤에도 같은 칩의 섹터 32-127 은 신품 대비 0.98-1.00 이었다 — 마모는 칩이 아니라 섹터에 쌓인다
- **프로그램 시간은 칩마다 갈렸다**(10만 회 빠른 1.00-2.09배 · 느린 1.21-2.15배) — 일관된 축이 못 되어 모델에서 뺐다

### 6) 수명 역산 — 측정 한 번으로 「몇 번 썼나」

쓰던 칩에는 신품 기록이 없다. 그래서 **같은 칩의 지운 적 없는 섹터(32-127)를 그 칩의 신품값으로** 쓴다. 닳은 섹터가 그보다
몇 배 느린지를 같은 무리의 교정 곡선(위 9칩, 100k 너머는 7장)에 대어, 누적 사용 횟수를 확률 구간으로 답한다. 입력은 소거 시간뿐이고
답 범위는 1-100,000회다. 아래는 발표에서 시연한 chip26(85°C 에서 70,000회 마모) 의 2026-11-01 측정 — prep 과 스윕을 합쳐 1분 53초였다.

```
입력 A  기준(32-127) 소거 중앙값 25.3ms → fast 무리 (교정 ['chip01', 'chip02', 'chip04', 'chip06', 'chip09', 'chip18']) · 눈금 ratio · R 2.80 (σ_r 0.486)
입력 B  마모 섹터 소거 7개 (prep 1회 · ρ_s 0 · ρ_p 0.78 · ρ_chip 0.21 · n_eff 3.10): 67.1, 68.6, 67.5, 70.7, 62.5, 61.2, 64.7 ms
답      평균 60,001-61,000 · 중앙값 60,001-61,000 · MAP 51,001-52,000 · 68% 31,001-85,000 · 95% 25,001-100,000
```

- **교차검증** — 교정 9칩을 하나씩 빼고 맞히기, 106점. 95% 구간이 정답의 94.5% 를 품어 먼저 정한 합격 띠(91.5-99.1%) 안이다.
  68% 구간은 81.7% 로 띠(59.4-76.4%) 위 — 구간이 필요보다 넓은 과소신이고, 안전한 쪽이라 고치지 않았다

### 7) 고온 마모 이력 — 65 · 85°C, 6칩

필름 히터와 아두이노 온도 제어로 칩을 데운 채 닳게 했다 — 설정 65°C 의 chip16 · 17, 85°C chip22 · 24(10만 회) · chip26 · 23(위 블라인드).
블라인드 두 칩의 판정 측정은 식혀서 상온에서 했다.

- **상온 칩의 개체 산포와 구별되지 않았다.** 온도에 따른 일관된 방향이 없다 — 같은 설정 65°C 의 chip16 은 10만 회 4.34배 · chip17 은
  2.44배로 상온 빠른 무리(2.60-3.97배)의 양쪽 바깥에 갈렸고, 85°C chip24 는 3.47배로 그 한가운데였다. 표본이 적어 「차이가 없다」 고 단정하지는 않는다
- 느린 무리 85°C 의 신호는 chip22 한 칩이다 — 10만 회 1.90배(상온 느린 세 칩 1.59-1.75배)이고 상온 모델의 68% 구간은 12점 중 3점만 맞았다. chip23 은 이 신호가 아니라 느린 신품의 다른 형으로 본다
- 상온 교정 모델의 95% 구간은 10만 회 네 칩 48점 중 47점을 품었지만 68% 구간은 22점만 맞았다 — 고온 이력 칩에는 넓은 범위로 답한다
- 폭은 고온 칩도 마모 중 3σ 안이었다

(`docs/results/wear/wear_temperature_85C.md` · `wear_temperature_chip16.md` · `wear_temperature_chip17.md`)

### 알아낸 것의 한계 (먼저 밝힘)

- **BER 10⁻¹² 외삽 폭은 제시하지 않는다.** 벽 천이가 위상 해상도(Δφ = 15.87ps, MMCM VCO 고정)보다 가팔라, 한 스텝 만에 BER이 10⁻⁴ → >5×10⁻²로 점프한다. 가우시안 꼬리 외삽의 자격 검증(probit 선형성, 편당 4점)에 표본이 3점밖에 안 잡혀 **구조적으로 성립하지 않는다** — 어느 클럭으로 올려도 같다.
- 다만 θ를 10⁻²에서 10⁻⁴로 조여도 실측 폭 변화가 27ps(0.07%)에 그쳐, 본 채널은 **결정론 성분이 지배하는 저지터 채널**로 판단되며 실측 폭의 대표성은 θ 선택에 둔감하다. 관측 범위 밖 추가 협착도 σⱼ ≤ 11ps 대입 시 양벽 합계 약 75ps(폭의 0.2%) 이내로 상한된다(보증이 아닌 모델 의존 상한).
- 추가 판독(포화 천장 0.246, 구간 기울기 비선형)은 단일 가우시안 모델의 부적합을 시사 → 후속 연구에서 2성분 지터 모델(dual-Dirac) 검토.
- **게재 등급은 25MHz만.** 45/75MHz는 사다리 교차검증 목적의 수집분으로, 원본 CSV는 커밋 대상이 아니다(재현 절차만 보존).
- **한 품번이다.** 모델은 W25Q64FV 에서만 검증했다. JV 두 칩(각 100k 한 점)은 FV 모델이 54-55k(v3.2) · 59-60k(v4)로 읽었다 — 같은 100k 의 FV 칩도 0.60-0.86배라 이 숫자는 품번 차이의 증거가 아니다. JV 는 계단 없이 늙는 다른 곡선이고 모델은 FV 에서만 검증했다. 품번마다 곡선을 따로 만들어야 한다.
- **마모한 느린 신품 7칩 중 3칩(chip12 · 21 · 23)은 빠르게 늙는 다른 형이다.** 신품 측정 한 번으로는 구별되지 않고, 모델은 이 형을 높게 읽으며(chip23 3.5배) 경고도 내지 않는다.
- **수명 역산은 고마모를 범위로 답한다.** 10만 회 쓴 칩을 약 0.7배(5장 판, 10/19 측정)로 낮게 읽는다 — 소거 시간이 100k 너머를 구분하지 못해서다. 대신 정답 50-100k 의 95% 구간 포함은 99.3%(5장 판, 10/19 측정)다.
  가장 빨리 늙는 칩(chip04)은 68% 구간이 34%(5장 판, 10/19 측정)만 품는다 — 같은 무리 안의 속도 차가 구간 폭의 바닥이다.
- **블라인드는 봉인 1칩(chip06)과 모델 고정 판정 2칩이다.** 3인 팀이라 완전 블라인드도 아니다(정답은 칩이 쥐고, 추정 커밋 뒤에 읽었다). 상온 느린 무리 블라인드 chip08 이 남았다.
- **실제 중고 칩에는 해 보지 못했다.** 닳은 섹터 위치를 아는 칩으로만 검증했다. 역산의 전제는 「지우지 않은 섹터가 칩에 남아 있다」 이라, 웨어 레벨링으로 고르게 닳은 칩에는 적용되지 않는다.
  진단은 섹터 0-127 을 지우고 써서 P/E 가 1회 늘고 내용이 지워진다 — 마모는 무시할 수준이지만 비파괴는 아니다.
- **온도는 마모 이력 2점(65 · 85°C)까지다.** 온도 계수(ps/°C)와 온도별 윈도우 곡선은 없고, 온도는 센서 자리 값이라 칩 내부 온도는 모른다. chip16 은 칩 온도를 확인하지 못했다. 전압 축 · 슈무 플롯은 레벨 시프터가 든 전용 보드가 전제인데 제작 전이라 하지 못했다.
- **대조군 섹터의 윈도우 폭은 재지 못했다** — 읽기 창이 섹터 0-6 에 고정이라, 대조군은 소거 시간으로만 봤다.

**재현**: 1)-3) 의 수치·그림은 `.venv/bin/python host/analysis/repeatability_aggregate.py <5개 CSV>` 로 재생성된다.
단 스윕 원본 CSV는 용량상 커밋 대상이 아니므로(`data/` 로컬 보관), clone 상태에서 되는 것은 **게재 요약본 열람**까지다 — 숫자를 다시 만들려면 실측이 필요하다. 명령은 `docs/commands.md`, 흐름과 상태는 `docs/project_pipeline.md`, 게이트별 기대 출력은 `docs/workflow/4.gate_map.md`.
