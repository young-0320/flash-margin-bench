# docs/spec — 사양서·합격 기준

**구현 전에 합격 조건을 못 박는 문서**의 보관소. 작성자는 한영웅(PE), 수신자는 구현
담당자 한 명이며, 인수 기준 판정으로 닫힌다.

`docs/interface/`와의 구분 — **계약은 3인이 동시에 지키는 것, 사양서는 한 사람에게
보내는 지시다.** 레지스터 맵·프로토콜·CSV 스키마처럼 여러 블록이 맞물리는 합의는
`interface/contract.md`(변경은 3인 합의 + `amendments/`), 한 사람의 구현 범위와 인수
조건을 정하는 문서는 여기.

## 규칙

- 파일명은 `s<번호>.<주제>.md` — 워크플로의 트랙 번호를 접두사로 유지한다
- 머리말에 **수신자 · 인수 판정자 · 근거 문서**를 명시한다. 작성자와 판정자가 같아도
  적는다 — 나중에 분리해야 할 때 누락이 드러난다
- 본문은 수치와 조건만 싣는다. **왜 그 값인가는 `docs/log/young/`** 에 남기고 링크한다
