## 1. 범위

개봉 전 prep 1회 이상의 섹터별 소거 시간에서, 마모 섹터 0-6 의 누적 P/E 사이클 x 를 구간으로 추정한다.
신품 기록 없이 칩 안의 값만 쓰는 1차(현장) 모델이다. 신품 집계표를 더하는 2차(참조) 모델은 구현하지 않았다.

## 3. 입력 (공통)

| 입력 | 정의 | 쓰임 |
|---|---|---|
| A | 섹터 32-127 소거 시간의 중앙값 | 이 칩의 신품값 · 무리 분류 · 배율의 분모 |
| B | 섹터 0-6 소거 시간 (prep k 회면 7k 개) | x 추정의 관측 |
| C | 섹터 0-6 프로그램 시간 (v1 · v2 만) | 무리 선택의 교차 확인 문구 — x 추정에 넣지 않는다. 중앙값 7.3ms 미만이면 「빠른 무리와 맞음」 |

- **무리**: A 가 40ms 미만이면 빠른 무리, 이상이면 느린 무리. 교정 곡선은 같은 무리의 칩만 쓴다
- **눈금**: 배율(ratio). 관측은 B ÷ A, 교정은 구간값 ÷ 그 칩의 신품 소거 중앙값(`newchip_survey_2026-09.csv`)
- **쓰지 않는 것**: 폭 · BER 바닥 · 집계표의 신품값(블라인드 칩) · 기준 섹터의 프로그램 시간 · 두 번째 dose Δx

## 4. 교정 (공통)

- **표**: `docs/results/data/wear_curves/wear_curves_chipNN_YYYY-MM.csv` — 마모 루프 A 행을 1,000사이클 구간 × 섹터로 묶은 p10 · p50 · p90
- **대상**: 이름에 접미사가 없는 표만. `_65C`(chip17) · `_ali`(chip12) · `_nocal` 은 교정이 아니다
- **구성원**: 무리 안 칩 × 섹터 하나가 그 구간의 구성원이다. 구성원마다 평균 p50 · 표준편차 (p90 − p10) ÷ 2.5631 의 정규분포
- **폭의 바닥**: 표준편차는 p50 의 2% 아래로 두지 않는다
- **범위**: 곡선 지점은 교정이 있는 데까지 쓴다(chip01 은 300k). 답하는 x 는 1 - 100,000

## 5. 계산 (공통)

1. **곡선 우도**: 곡선 지점(1k 구간) M 마다, 관측별 「구성원 밀도의 평균」 의 로그를 관측 수로 나눠 더한다(기하 평균).
   prep 을 여러 번 돌려도 관측 전부를 한 덩어리로 친다
2. **속도 배율 r**: 누적 x 인 칩은 곡선의 M = x · r 지점처럼 보인다고 두고, r 을 [1/R, R] 에서 로그 등간격 41점으로 평균한다.
   곡선에 없는 지점의 기여는 0 이다. R 이 1 이하면 r = 1 하나
3. **사전**: x 는 1 - 100,000 의 1k 구간에 균등
4. **사후**: 구간별 값을 합이 1 이 되게 정규화한다

## 6. 출력 (공통)

| 출력 | 정의 |
|---|---|
| MAP 구간 | 사후 확률이 가장 큰 1k 구간 |
| 사후 중앙값 구간 | 누적 사후 확률이 처음 절반에 닿는 1k 구간 (v3 부터 대표값) |
| HPD 68% · 95% | 확률이 큰 구간부터 모아 누적이 68% · 95% 에 닿을 때까지의 집합. 이어진 구간은 한 범위로 합쳐 적는다 |
| 밴드 밖 관측 수 | r 없이 곡선 우도가 가장 큰 지점에서, 구성원 p10 최소 - p90 최대 밖에 있는 관측의 수 |
| 등급 (화면, 2026-10-02 부터) | 사후 확률의 합이 가장 큰 등급 — 정격 100,000 대비 신품 1% 이하 · 저마모 20% 이하 · 중마모 60% 이하 · 고마모 100% 이하 |

- **보류**: 관측이 전부 밴드 밖이면 판정을 내지 않는다. 단 곡선 첫 구간보다 전부 아래면 신품 쪽으로 읽고 보류하지 않는다
- **기록** (`--out`): 입력 A 줄 · 입력 B 줄 · (v1 · v2 는 입력 C 줄) · 답 줄 · 주의 줄. 머리말에 git 리비전 · 인자 · 입력 로그 sha256 · 교정 표 목록
- 100,000 너머는 답하지 않는다

## 7. 모의 블라인드 (LOCO)

- 교정 칩 하나를 빼고, 그 칩의 구간별 섹터 p50 7개를 관측으로 넣어 나머지 칩으로 추정한다. 신품값은 집계표 값
- 정답 지점 12점: 1,000 · 3,000 · 10,000 - 100,000 (10,000 간격). 표에 구간이 없는 점은 뺀다(chip07 60k · 80k)
- 같은 무리에 남는 칩이 없으면 그 칩은 뺀다
- 지표: 정답 ∈ 68% · 정답 ∈ 95% · 68% 폭(HPD 조각 길이의 합)의 중앙값
- 명령: `uv run python host/analysis/wear_inverse.py --loco` (현행 판) · `--rate-range R` (두 무리에 같은 R)
