## 1. 범위

개봉 전 prep 1회 이상의 섹터별 소거 시간에서, 마모 섹터 0-6 의 누적 P/E 사이클 x 를 구간으로 추정한다.
신품 기록 없이 칩 안의 값만 쓰는 1차(현장) 모델이다. 신품 집계표를 더하는 2차(참조) 모델은 구현하지 않았다.

## 3. 입력 (공통)

| 입력 | 정의 | 쓰임 |
|---|---|---|
| A | 섹터 32-127 소거 시간의 중앙값 | 이 칩의 신품값 · 무리 분류 · 배율의 분모 |
| B | 섹터 0-6 소거 시간 (prep k 회면 7k 개) | x 추정의 관측 |
| C | 섹터 0-6 프로그램 시간 (v1 · v2 만) | 무리 선택의 교차 확인 문구 — x 추정에 넣지 않는다. 중앙값 7.3ms 미만이면 「빠른 무리와 맞음」 |

- **무리**: A 가 40ms 미만이면 빠른 무리, 이상이면 느린 무리. 교정 곡선은 같은 무리의 칩만 쓴다
- **눈금**: 배율(ratio). 관측은 B ÷ A, 교정은 구간값 ÷ 그 칩의 신품 소거 중앙값(`newchip_survey_2026-09.csv`)
- **쓰지 않는 것**: 폭 · BER 바닥 · 집계표의 신품값(블라인드 칩) · 기준 섹터의 프로그램 시간 · 두 번째 dose Δx

## 4. 교정 (공통)

- **표**: `docs/results/data/wear_curves/wear_curves_chipNN_YYYY-MM.csv` — 마모 루프 A 행을 1,000사이클 구간 × 섹터로 묶은 p10 · p50 · p90
- **대상**: 이름에 접미사가 없는 표만. `_65C`(chip17) · `_ali`(chip12) · `_nocal` 은 교정이 아니다
- **구성원**: 무리 안 칩 × 섹터 하나가 그 구간의 구성원이다. 구성원마다 평균 p50 · 표준편차 (p90 − p10) ÷ 2.5631 의 정규분포
- **폭의 바닥**: 표준편차는 p50 의 2% 아래로 두지 않는다
- **범위**: 곡선 지점은 교정이 있는 데까지 쓴다(chip01 은 300k). 답하는 x 는 1 - 100,000
- **v4 셀 분포**: 표에 `erase_us_q00 … q100`(5% 간격 분위수 21개, `wear_curves.py` 가 같이 쓴다)이 있어야 한다. 구성원은 이웃 분위수 사이
  조각마다 5% 의 균일 밀도(0.05 ÷ 조각 폭) — 모양을 가정하지 않아 계단 전환 셀의 빈 구간이 그대로 낮은 밀도가 된다. 조각 폭 하한 1µs(A 행 해상도),
  분위수 밖의 밀도 1/1,001 ÷ (q100 − q00)(1,001번째 표본의 몫). 둘 다 표본 수와 해상도에서 오는 값이라 고르지 않는다. 밴드 검사의 p10 · p90 은 q10 · q90
- **v4 정렬**: 무리 안 쌍마다 `pair_speed`(양방향 로그 평균)를 ŝ_a − ŝ_b = ln r_ab 로 두고 최소제곱으로 칩당 로그 속도 ŝ_j (무리 안 합 0).
  공통 시계 구간 B 마다 칩 j 의 (B 가운데) ÷ r̂_j 가 든 셀을 구성원으로 넣는다. 가장 가까운 셀을 그대로 쓰고 보간하지 않는다(계단 앞뒤를 섞으면
  한 번도 안 나온 중간값이 생긴다). 빠른 칩(r̂ > 1)의 100k 는 공통 시계 100k·r̂ 까지 늘어나고, 느린 칩(r̂ < 1)은 그 전에 끝난다

## 5. 계산 (공통)

1. **곡선 우도**: 곡선 지점(1k 구간) M 마다, 관측별 「구성원 밀도의 평균」 의 로그를 관측 수로 나눠 더한다(기하 평균).
   prep 을 여러 번 돌려도 관측 전부를 한 덩어리로 친다
2. **속도 배율 r**: 누적 x 인 칩은 곡선의 M = x · r 지점처럼 보인다고 두고, r 을 [1/R, R] 에서 로그 균등으로 적분한다.
   곡선에 없는 지점의 기여는 0 이다. R 이 1 이하면 r = 1 하나
   - v3.1 까지: r 을 로그 등간격 41점으로 찍어 평균한다
   - v3.2: 격자 없이 — x 구간 가운데 c 에 대해 곡선 범위 [c/R, c·R] 에 걸치는 1k 구간을 모두 더하고, 구간마다
     ln(걸친 끝 ÷ 걸친 시작)을 곱한다 (1k 구간은 [시작, 시작 + 1000))
3. **사전**: x 는 1 - 100,000 의 1k 구간에 균등
4. **사후**: 구간별 값을 합이 1 이 되게 정규화한다
5. **v4 증거량**: 1 의 기하 평균에 유효 관측 수 n_eff 를 곱한다 — k 섹터 × P prep 의 평균이 줄이는 분산의 역수. 관측 하나가 교정 곡선에서
   벗어나는 분산을 넷으로 나눈다: 칩 효과 ρ_chip(이 칩이 교정 혼합에서 7섹터 · 모든 prep 에 공통으로 벗어나는 몫 — 늘려도 안 준다) · 칩 안 몫
   1 − ρ_chip 안에서 ρ_s = 같은 prep 안 섹터 간, ρ_p = 같은 섹터 prep 간 상관
   `n_eff = 1 / (ρ_chip + (1 − ρ_chip)·(ρ_s/P + ρ_p/k + (1 − ρ_s − ρ_p)/(k·P)))`.
   ρ_chip 0 · ρ_s 1 · P 1 이면 v3 와 같고(1), 전부 0 이면 독립 곱(k·P), ρ_chip 이 c 면 1/c 를 못 넘는다. 값은 `--rho` 로 잰다: ρ_s · ρ_p 는 교정 A 행에서
   연속 사이클 P 개 × 7섹터 표(구간당 20개, 연속이라 추세는 무시할 만하다)의 이원 랜덤효과 적률 추정 — 행(prep) 효과의 몫이 ρ_s, 열(섹터) 효과의 몫이
   ρ_p. ρ_chip 은 칩 안 표로는 보이지 않으므로(칩 효과가 표 전체의 상수라 평균에 묻힌다) 교정 칩을 하나씩 빼고 그 칩의 A 행 한 줄(7섹터)을 나머지
   칩의 정렬된 혼합(공통 시계 b·r̂_j 의 구성원 p50 중앙값)과 비교한 로그 잔차 표의 일원 랜덤효과 — 표 간 분산의 몫. 블라인드 prep 로그(같은 표 꼴)로
   ρ_s · ρ_p 가 마모 루프의 값과 비슷한지 본다. 셋 다 **전체값 하나**를 등록한다(무리별로 두지 않는다 — 칩 3개짜리 무리의 값은 운일 수 있고 규칙이
   둘이 된다). 잰 값은 코드 `RHO` 에 출처와 함께 등록한다 — **등록 전에는 v4 가 돌지 않는다**(--rho-sector/--rho-prep/--rho-chip 은 시험용).
   2026-10-09 등록: ρ_s 0.00 · ρ_p 0.78 · ρ_chip 0.29 (빠른 0.33 · 느린 0.03 은 발견으로만)
6. **v4 R**: 정렬에 쓴 ŝ_j 의 표준편차 σ_r (무리마다 합 0 이라 Σŝ² ÷ (M − 1)) 에서 `R = exp(1.96 · σ_r · √(1 + 1/M))` — 새 칩 하나 대 교정 M개 평균의
   95% 범위. v1 · v2 규칙의 √2 가 √(1 + 1/M) 로 준 것이 이중 계산을 뺀 효과다. 무리에 칩이 하나면 두 무리를 합친 σ_r 을 쓴다(가정이라 기록에 적는다).
   `--rate-range` 를 주면 그 값이 이긴다. 2026-10-08 교정 8칩 미리보기: 빠른 σ_r 0.507 (M 5) → 2.97 · 느린 0.184 (M 3) → 1.52

## 6. 출력 (공통)

| 출력 | 정의 |
|---|---|
| MAP 구간 | 사후 확률이 가장 큰 1k 구간 |
| 사후 중앙값 구간 | 누적 사후 확률이 처음 절반에 닿는 1k 구간 (v3 부터 대표값) |

- **보류**: 관측이 전부 밴드 밖이면 판정을 내지 않는다. 단 곡선 첫 구간보다 전부 아래면 신품 쪽으로 읽고 보류하지 않는다
- **기록** (`--out`): 입력 A 줄 · 입력 B 줄 · (v1 · v2 는 입력 C 줄) · 답 줄 · 주의 줄. 머리말에 모델 버전(v3.2 부터) · git 리비전 · 인자 · 입력 로그 sha256 · 교정 표 목록
- 100,000 너머는 답하지 않는다

## 7. 모의 블라인드 (LOCO)

- 교정 칩 하나를 빼고, 그 칩의 구간별 섹터 p50 7개를 관측으로 넣어 나머지 칩으로 추정한다. 신품값은 집계표 값. v4 의 등록 수치는 아래 rows 관측
- 정답 지점 12점: 1,000 · 3,000 · 10,000 - 100,000 (10,000 간격). 표에 구간이 없는 점은 뺀다(chip07 60k · 80k)
- 같은 무리에 남는 칩이 없으면 그 칩은 뺀다
- 지표: 정답 ∈ 68% · 정답 ∈ 95% · 68% 폭(HPD 조각 길이의 합)의 중앙값
- 명령: `uv run python host/analysis/wear_inverse.py --loco` (현행 버전) · `--rate-range R` (두 무리에 같은 R)
- **v4 관측**: 빠진 칩의 그 1k 구간 A 행에서 사이클 P 개를 뽑아 7섹터를 **그대로** 넣는다(`--loco-obs rows --prep-k P`, 7·P 개). 같은 사이클의
  7섹터를 함께 쓰므로 한 prep 안의 섹터 상관이 실전처럼 들어가고, 실전처럼 한 번 잰 값의 흔들림이 있다. 정렬 · σ_r · R 은 빠진 칩 없는 교정으로
  다시 낸다(누수 없음). seed · 반복 횟수를 적는다. A 행이 없는 칩은 이유와 함께 뺀다
- **v4 합격 띠 (돌리기 전에 정한다)**: 점 수 n 과 명목 q 에서 `n·q ± 1.96·√(n·q·(1−q))` (올림 · 내림). 띠 안이면 합격, 아래면 과신, 위면 과소신.
  58점이면 68% 는 33-46점 · 95% 는 52-58점. 점들이 칩 몇 개에서 나와 독립이 아니라 띠는 실제보다 좁다 — 띠 안은 「틀렸다는 증거 없음」이다.
  띠 밖일 때 의심 순서: 과신이면 ① 분위수 바닥 · 조각 폭 하한 ② 정렬 부족 ③ 구성원 수 M, 과소신이면 ① ρ 측정(연속 사이클 수 · 추세) ② R.
  결과를 본 뒤 순서를 바꾸지 않는다. 코드가 띠와 판정을 LOCO 출력 끝에 찍는다.
  2026-10-09 등록 때의 경위: ρ_chip 없는 식으로 95% 가 과신이었고, 위 순서의 ① - ③ 이 아니라 **ρ 의 정의**(칩 효과를 못 보는 표)가 원인이었다
  — 순서를 바꾼 것이 아니라 재는 양을 고친 것이다(로그 52 §9). 다음부터 과신의 ⓪ 은 「ρ 가 칩 효과를 재고 있나」
