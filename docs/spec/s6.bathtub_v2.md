# S-6. 욕조 v2 측정 명세 — 훑기 → 벽 집중

- **상태: 초안 (2026-11-11).** 계약에 닿는 부분(레지스터 · 규약 · 파일)은 [수정안 #4](../interface/amendments/4.edge_counter_bathtub_v2.md) 가 정본이다. 이 문서는 측정 절차 · 파라미터 · 시험을 정한다
- **근거**: [로그 55](../log/young/55.professor_feedback_bathtub_2026-11-02.md) [D55-3] - [D55-13] · 개념 [16 에지 계수기](../concepts/16.edge_counter.md)
- **범위**: 졸업논문 「기각한 지표와 그 이유」 장([D55-8]) — 벽이 에지 방향으로 갈리고(DCD), 그 시간 차가 마모와 무관함을 보이는 데까지. 마모 체크포인트 스윕은 v1 그대로다([D55-10])

## 1. 무엇을 재나

v1 은 위상 2,520스텝 전부를 같은 N(112)으로 읽어 바닥까지 같은 깊이로 본다. v2 는 **바닥을 1회 훑기로만 지나가고, 벽과 그 바깥에 읽기를 몰아** 벽의 꼬리를 깊게 본다. 그리고 에지 계수기로 벽을 상승 에지 · 하강 에지로 나눈다.

## 2. 파라미터

| 이름 | 값 | 근거 |
| ---- | -- | ---- |
| SCLK | 25MHz (UI 40,000ps · 2,520스텝 · 15.87ps) | [D55-7] — 마모 체크포인트 386런과 연속 |
| 훑기 N | 1 (스텝당 2,048비트) | 로그 55 §6 — 천장은 1회로 100% 잡힌다 |
| 천장 판정 | 훑기에서 오류 ≥ 205 (BER ≥ 0.1) | [D55-4] |
| 천장 N | 112 (한 묶음) | [D55-4] — 천장은 매번 같은 값이다 |
| 벽 N — 표준 `std` | 8,064 = 112 × 72 (START 72번) | [D55-5] — 보통 칩에서 v1 과 같은 시간 |
| 벽 N — 초심부 `deep` | 2,064,384 = 112 × 18,432 (START 18,432번) | [D55-11] — 0 오류면 BER 7e-10 아래(95%) |
| K (멈춤) | 5 — 벽 N 으로 0 오류 스텝이 5개 연속이면 그 방향을 멈춘다 | [D55-4] |
| 바깥 상한 | 훑기 덩어리 경계에서 바깥으로 64스텝(약 1,000ps) | [D55-4] — 넘으면 무효 ⑩ `wall_cap` |
| 덩어리 정의 | 가장 긴 원형 0 구간(바닥)의 여집합. 안쪽 0 틈이 K 미만이면 같은 덩어리, K 이상이면 무효 ⑨ `multi_block` | [D55-4] |
| 이력 범위 | 덩어리 중심 스텝 580-760 — 밖이면 `block_out_of_range` 표시 | v1 386런 594-746 에 여유. A4 뒤 다시 맞춘다 |
| 끝 훑기 | 벽 집중이 끝난 뒤 훑기를 한 번 더 — 덩어리 경계가 1스텝 넘게 다르면 `drift` 표시 | 리뷰 §9 확인 필요 1(초심부 수 시간의 표류) |
| N 은 실행 때 덮어쓴다 | `std` · `deep` 는 같은 ELF, 변수만 다르다(`g_uart_baud` 와 같은 방식, 로그 49) | [D55-5] |

N 은 한 START 에 2,048 이하(계약 R6 · R11)라 벽 N 은 **112회 START 를 반복** 해서 채운다. 묶음마다 `e_i` 와 정렬별 여섯 값 버퍼를 다음 START 전에 회수한다(R3).

## 3. 절차

```
① 시작     ID == 0x4D42_0200 확인 (아니면 무효 ⑪) · BEGIN 줄
② 훑기     스텝 0 → 2519, 스텝마다 START 1회(N = 1). 행 pass=scan
③ 덩어리   훑기 결과로 바닥(가장 긴 원형 0 구간)과 덩어리를 정한다
            · 안쪽 0 틈 ≥ K → 무효 ⑨ 로 끝낸다
            · 중심이 이력 범위 밖 → flags 에 block_out_of_range
④ 천장     덩어리 안에서 훑기 오류 ≥ 205 인 스텝 → 112회 한 묶음. 행 pass=ceil
⑤ 벽 집중  덩어리 안의 나머지 스텝(벽) → 벽 N. 행 pass=wall
            왼쪽 경계에서 바깥(스텝 감소)으로 한 스텝씩 벽 N — 0 오류가 K 연속이면 멈춘다
            오른쪽 경계에서 바깥(스텝 증가)으로 같은 방식
            어느 쪽이든 64스텝을 넘으면 무효 ⑩ 로 끝낸다
⑥ 끝 훑기  ② 를 한 번 더. 행 pass=rescan. 경계가 1스텝 넘게 다르면 flags 에 drift
⑦ 끝       END 줄에 main_rows · reads_rows
```

- 위상 이동은 `PHASE_INC` · `PHASE_DEC` 만 쓴다. 이동은 측정 사이(R2)이고 `PHASE_POS` 로 매번 위치를 확인한다(현행 `phase_pos_mismatch` 검사와 같다). 위상축은 원형이라 스텝 번호는 2,520 으로 나눈 나머지로 다룬다 — 덩어리가 2519 → 0 경계에 걸쳐도 같은 절차다.
- ⑤ 에서 「0 오류 K 연속」 은 벽 N 으로 잰 결과로 판정한다. 훑기 결과로 판정하지 않는다 — 1회 훑기는 경계를 안쪽으로 최대 7스텝 놓친다(로그 55 §6).

## 4. 시간 (추정 — A4 에서 실측으로 바꾼다)

| 모드 | 벽 집중 스텝(보통 칩) | 스윕 1회 |
| ---- | --------------------- | -------- |
| `std` | 약 20 | 약 1-2분 + 훑기 두 번 |
| `deep` | 약 20 | 약 3.2시간 (원본 기록 포함, 읽기 1회 약 283µs — 정렬별 여섯 값이 붙어 UART 몫이 늘면 더 길다) |

JV 칩은 천장이 길지만 천장은 한 묶음이라 벽 스텝 수는 비슷하다.

## 5. 분석 (호스트)

- **입력**: `bathtub2_*` 만. v1 분석기는 v2 파일을 읽지 않는다(접두사 · `n_reads` 섞임 검사 — 로그 55 §9 R6).
- **그림**: 끊긴 축(P1), 한쪽 W = 1,000ps, 바닥 길이는 화살표와 수치([D55-3]). 바닥 구간은 `scan` 행으로 그리고 「1회 훑기 — 깊이 다름」 을 표시한다.
- **에지별 곡선**: `_reads.csv` 의 정렬별 여섯 값에서 PC 가 읽기마다 승자를 정하고, 개념 16 의 해석(방향 = 정답 비트, 일찍 · 늦게 = 승자 정렬과 위상 순서로 추적한 앞 · 다음 비트 대응)으로 상승 · 하강에 나눠 누적분포 → pdf. 해석은 A2(시뮬레이션) · A5(75MHz 실칩 정답 대조)를 통과한 뒤에만 쓴다.
- **원본 다루기**: 초심부 원본은 스윕당 약 1.7GB, 한 칩 20-60회면 수십 GB 다. `data/bathtub2/<chip>/` 아래에 따로 두고, 받은 자리에서 정제(요약 CSV)까지 한 번에 끝낸다. 원본은 커밋하지 않는다(`data/` 원본은 원래 커밋 대상이 아니다).
- **BER 상한**: 벽 바깥 0 오류 스텝은 「BER < 3 ÷ (N × 2,048)」(95%)로 적는다 — `deep` 이면 7e-10.
