## 0. 먼저 — 초안에서 뒤집힌 것 5가지

| # | 초안의 전제 | 레포 실측 | 근거 |
|---|---|---|---|
| 1 | Δφ = 14.9ps (833ps/56, VCO 1,200MHz 가정). 기존 문서 12.8ps는 오류 | **15.873ps** (VCO 1,125MHz = 888.9ps ÷ 56). 12.8ps는 레포 어디에도 없음 — 전 문서가 15.87로 통일되어 있다 | `docs/interface/contract.md:80`, `fpga/rtl/core/core_mmcm.v:38` |
| 2 | 보드 상향 시 15ps → 11.2ps, **25% 개선**뿐이라 근거가 못 된다 | **MMCM 경로만 보면 맞다** — 이 칩 등급 상한 1.2GHz → 14.9ps(6%), 그마저 D=5가 필요해 지터가 나빠진다. 하지만 US+ **IDELAYE3(2.5ps 탭)** 경로는 별개이고 필요 구간에 들어간다 (§3.4) | `docs/concepts/11...:32`, `docs/concepts/2...:38-42`, UG571/UG974 |
| 3 | 15ps는 이미 노이즈 바닥 아래 (지터 RMS ~10ps와 동일 스케일) | 폭 반복 편차 **σ = 0.61ps** — 스텝의 1/26. 폭은 벽 교점 보간으로 나오므로 스텝 크기에 갇히지 않는다 | `README.md:53` |
| 4 | 반복 측정 + Gaussian CDF 피팅이 보드 교체보다 레버리지가 크다 | **이미 시도했고 구조적으로 실패했다.** probit 대역(BER 1e-4~5e-2) 표본이 편당 3점(필요 4점)이고 25/45/75MHz 전부 동일. 위상 격자가 고정이라 N을 늘려도 점 개수는 늘지 않는다 | `docs/log/young/15...:39`, `README.md:71` |
| 5 | 실행 1순위 = NOR 클럭 vs 윈도우 폭 예비 실험 | **완료됨.** G3 클럭 사다리가 그 실험이다 (25/45/75MHz 완주) | `README.md:36-49` |

4번이 가장 중요하다. 초안은 "0원 레버리지"로 커브 피팅을 꼽았는데, 이 채널에서는
그 카드가 이미 소진됐다. 벽 천이가 한 스텝 만에 BER 1e-4 → >5e-2로 점프해서,
비탈을 분해하려면 **2~3ps 자**가 필요하다 (`docs/concepts/11...:29-35`).

2번은 **MMCM 경로에 한정된 진술**이다. 위상 스텝 = VCO주기/56이라 개선 배수 = VCO
주파수 비율인데, Xilinx 전 제품군의 VCO가 1.1~1.6GHz 안에 다 들어가서 어떤 보드로도
1.4배가 상한이다. 7배가 필요한 상황에서 1.4배는 아무 결정도 바꾸지 못한다.

**그러나 해상도 개선 경로가 없다는 뜻은 아니다.** 지연 소자(IDELAY) 경로가 따로 있고,
UltraScale+ IDELAYE3의 탭은 2.5ps로 필요 구간에 들어간다 — §3.4에서 상술. 현 보드의
IDELAYE2(최선 39ps)로는 안 되므로 이것은 **보드에 종속된 능력**이다.

정리하면, 현 보드에 남는 결론은 이렇다: **폭 측정은 이미 sub-ps 반복성으로 성립하고
있고(σ = 0.61ps), 막힌 것은 폭이 아니라 비탈 분해다.** θ를 1e-2에서 1e-4로 조여도 폭이
27ps(0.07%)밖에 안 변하므로 폭 자체는 외삽 없이 직독 가능하다. 즉 claim은 현 보드로
증명되고, 상위 보드는 **새 기여를 추가**하는 선택지다 — 막힌 것을 뚫는 수단이 아니다.

## 1. SCI 등급·일정 (초안 유지)

초안의 등급 구분과 일정 리스크 판단은 레포와 충돌하지 않는다. 그대로 둔다.

- 졸업논문(2027 상반기, 내부 심사)과 SCI 투고(게재 시점 무관)를 **분리**한다.
- 학과 규정상 게재확정이 졸업 요건인지 확인 — 요건이면 저널 등급이 하위로 강제된다.
- 국내 학회(대한전자공학회) 병행 — 이미 있는 G0~G4 데이터로 추가 작업 거의 없음.

**초안에 없던 리스크 하나 추가: 저자 배분.**
이 프로젝트는 3인 팀이고(`docs/roles.md`), RTL·펌웨어·DUT 보드가 각각 다른 소유자에게
있다. 논문 1저자·교신저자 배분을 **데이터를 더 쌓기 전에** 교수님·팀원과 합의해야 한다.
계측 엔진(코어 RTL)·실험 설계·분석이 한영웅 소유라 1저자 근거 자체는 명확하지만,
합의 없이 진행하면 나중에 되돌릴 수 없다.

**데이터 정책 충돌도 하나.** 레포는 원본 CSV를 커밋하지 않는 정책이다(`README.md:122`).
다수 저널이 data availability statement를 요구하므로, 투고 시점에 게재 수치의 근거
데이터를 외부 아카이브(Zenodo 등)로 공개할 준비가 필요하다. 지금 정책을 바꿀 필요는
없고, 투고 체크리스트에만 넣어 두면 된다.

## 2. 프로젝트 실체 — 초안 서술의 갱신

초안의 "타이밍 마진 계측 플랫폼" 서술은 맞다. 갱신할 부분만:

- **DUT**: SPI NOR W25Q64 ×10 확보 완료. SPI NAND(W25N)는 **조달 대기** — 아직 레포에
  코드가 없다(`fpga/rtl/flash/README.md`의 NOR/NAND 분화는 "W25N 착수 시" 조건부).
- **PL 구현 현황**: 위상 스윕 엔진·가변클럭 SPI·패턴 비교기·CDC는 **구현·실증 완료**(G0~G4).
  **P/E 사이클링 엔진·op_timer(10ns)·error logger·ECC는 아직 TODO**
  (`fpga/rtl/flash/README.md`). 초안은 이것들을 기존 자산처럼 전제하고 있는데, 실제로는
  마모 실험의 선행 구현 항목이다. 일정에 반드시 넣어야 한다.
- **온도·전압 축**: 계획에는 있으나 **의도적 미착수**. 히터·레벨 시프터가 실린 전용 DUT
  보드가 전제다(`docs/project_context.md:245`). 현재 크리티컬 패스는 FPGA 보드가 아니라
  **이 DUT 보드**다.

## 3. 해상도 문제 — 재정리

### 3.1 자의 정체

Δφ = VCO주기/56 = 888.9ps/56 = **15.873ps**. VCO 1,125MHz는 M=9·D=1로 만들어졌고,
이 구성은 해상도가 아니라 **지터**를 기준으로 선택됐다: VCO를 정확히 1,200MHz로 만들려면
D=5가 필요해서(125×48÷5) 피드백 비교가 뜸해지고 지터가 는다. 눈금 1ps를 얻으려고 자의
떨림을 키우는 역설이라 기각했다(계약 결정 16).

즉 **"해상도가 부족하니 VCO를 올리자"는 이미 검토·기각된 경로**다. 교수님께 보드 이야기를
꺼낼 때 이 결정 이력을 먼저 말해야 한다 — 안 그러면 검토 안 한 것으로 보인다.

### 3.2 판단 기준은 SNR — 여기까지는 초안이 맞다

다만 분모의 정체가 초안과 다르다.

| 항목 | 초안 | 실측 |
|---|---|---|
| 폭 측정 재현 편차 | (미상, 지터 ~10ps로 추정) | **0.61ps** (25MHz ×5회, 재장착 없음) |
| θ 민감도 | (미검토) | **27ps** (θ 1e-2→1e-4, 폭의 0.07%) |
| 벽 모서리 σⱼ | ~10ps 추정 | **6~11ps** (2점 probit, 두 스윕 네 모서리 일관) |

분모는 0.61ps다(재장착·보드·일자를 포함하지 않은 EV 한 조각이라는 단서는 붙는다 —
`README.md:141`의 Gage R&R 축이 그것). 따라서 **마모로 폭이 수십 ps만 움직여도 검출된다.**
초안이 "50ps면 3스텝이라 논문 불가"라고 본 것은 스텝 크기를 분모로 놓은 결과인데,
실제 분모는 그보다 26배 작다. **50ps 이동은 σ의 80배로, 충분히 논문 가능하다.**

이건 초안 대비 순증한 여유다. 남은 위험은 "마모가 폭을 움직이는가" 자체이지, 잴 수
있는가가 아니다.

### 3.3 효과 크기를 키우는 법 — 실측이 방향을 지시한다

초안의 "클럭을 스펙 한계까지 올려라"는 **실측으로 지지된다**:

| 클럭 | UI 대비 마진 | 벽 폭 |
|---|---|---|
| 25MHz | 99.3% | ~302ps |
| 45MHz | 98.5% | ~381ps |
| 75MHz | **91.5%** | **~1,175ps** |

25MHz는 UI의 99.3%가 열려 있어 **마모 신호를 볼 자리가 아니다**. 마모 실험의 관측점은
**75MHz 이상**이어야 한다. 그리고 벽 폭이 클럭에 따라 체계적으로 넓어지므로, 고클럭에서는
비탈 표본도 더 잡힌다(75MHz 74스텝) — 체크1이 살아날 가능성이 있는 유일한 방향이기도 하다.

> 실험 설계 지시: 마모 체크포인트 측정은 최소 **25MHz(대조) + 75MHz(관측)** 2점으로 찍는다.
> 25MHz만 찍으면 효과가 있어도 못 본다.

### 3.4 IDELAY — 상위 보드에 실재하는 해상도 경로

MMCM 산수(3.1)는 "VCO 상향으로는 못 간다"만 말할 뿐이고, **해상도 개선 경로가 없다는
뜻이 아니다.** 지연 소자 경로가 따로 있다.

| 소자 | 탭 수 | 탭 크기 | Δφ(15.87ps) 대비 |
|---|---|---|---|
| 7-series IDELAYE2 (현 보드) | 31 | REFCLK 200/300/400MHz → **78 / 56 / 39ps** | 최선도 2.5배 **굵다** — 사용 불가 |
| UltraScale+ IDELAYE3 | 512 | TIME 모드 **2.5ps 공칭** (원시 탭 2.1~12ps, IDELAYCTRL이 PVT 보상) | **6배 미세** |

2.5ps는 `docs/concepts/11...:32`가 "비탈 분해에 필요"라고 적은 2~3ps 구간에 정확히 들어간다.
**즉 상위 보드의 해상도 근거는 실재한다** — 다만 MMCM이 아니라 IDELAYE3를 지나간다.

**무엇이 열리나**: 벽 천이(약 1스텝 = 15.87ps)에 표본이 6점가량 잡힌다 → 체크1(probit
편당 4점) 성립 → σ_RJ 분리 → dual-Dirac 2성분 모델 → **BER 1e-12 외삽**. 현재 README가
"구조적으로 성립하지 않는다"고 명시한 한계(`README.md:71`)가 바로 이것이고, 이 보드에서는
어떤 방법으로도 안 되지만 US+에서는 열린다.

**대신 계측기 구조가 바뀐다 — 보드 교체가 아니라 재설계다.**

- IDELAY는 **데이터 입력**에 걸린다. 샘플 클럭 위상을 미는 현재 방식이 아니라, 고정 클럭에
  대해 **데이터 지연을 스윕**하는 방식이 된다(DDR read training·SerDes의 표준 기법).
  스윕 엔진 RTL·스텝 계산·CSV 스키마·분석기가 전부 영향을 받는다.
- 지연선은 탭이 균일하지 않다(DNL/INL). 2.5ps는 공칭값이고, 자로 쓰려면 **탭별 교정**
  (code density test)이 필요하다 — TDC 문헌의 표준 절차다.
- 원시 탭이 PVT에서 2.1~12ps로 변한다. 이 프로젝트는 온도를 **일부러 흔드는** 실험이라,
  TIME 모드 PVT 보상이 온도 축에서 실제로 유지되는지가 별도 검증 항목이 된다.
- HD 뱅크에서 IDELAY 가용 여부는 확인 못 했다 — 보드 선정 시 **DUT 핀을 HP 뱅크에
  배치할 수 있는지** 확인 필요(§9).

**그런데 이건 claim의 병목이 아니다.** 논문의 1문장은 마모→마진 상관에 걸려 있고, 그건
현재 0.61ps 반복성으로 이미 측정 가능하다(3.2). IDELAYE3가 여는 것은 **다른 기여**
(지터 분해·외삽)이지, 막힌 것을 뚫는 게 아니다. 우선순위 판단은 §3.5.

### 3.5 그래서 상위 보드의 실제 가치

근거는 **둘**이고, 성격이 다르다.

1. **다중 DUT 병렬 구동** — P/E 사이클링 wall clock 단축. 12개월 일정의 최대 리스크를 직접 공략.
2. **IDELAYE3 2.5ps 해상도** — 지터 분해·BER 외삽이라는 **새 기여**를 연다(3.4).

교수님께는 둘 다 말하되 **역할을 구분해서** 말해야 한다: 1번은 일정 리스크 대응이고,
2번은 논문 범위 확장이다. "지금 측정이 안 돼서 보드가 필요하다"고는 말할 수 없다 —
0.61ps 반복성으로 이미 되고 있고, 그 사실이 오히려 이 플랫폼의 판매 포인트이기 때문이다.

**우선순위는 그대로 유지한다.** 현재 크리티컬 패스는 FPGA가 아니라 DUT 보드(히터·레벨
시프터)와 미구현 RTL(P/E 사이클러·op_timer)이다. 그리고 3.4의 재설계 비용(스윕 엔진
전면 수정 + 탭 교정)은 마모 파일럿(§7-2)이 claim을 확정하기 전에 지불할 성격이 아니다.

> 판단: 상위 보드는 **파일럿 이후**. 단 조달 리드타임이 길면 요청은 먼저 넣되,
> 착수는 파일럿 결과를 보고 결정한다.

**요청 순서: ① DUT 보드(온도·전압 축 개통) → ② 칩 추가(개체 산포 n≥30) → ③ 상위 FPGA(병렬 마모).**

## 4. 물리 메커니즘 — 미검증 전제의 현재 위치

### 4.1 NOR

초안의 "고클럭에서만 발현" 가설은 그대로 유효하며, **채널 물리가 고클럭에서 드러난다는
것까지는 실증됐다**(3.3의 벽 폭 302→1,175ps). 단 이것은 채널 대역폭 효과이지 마모 효과가
아니다. **마모 → 마진 축소 연결은 여전히 미검증이며, 이 프로젝트 최대의 단일 리스크다.**

레포는 이 리스크를 이미 정직하게 다루고 있다(`docs/project_context.md:74`) — 노화 지표
이중화(① 윈도우 폭 = 가설 검증 대상, ② 소거·쓰기 시간 = 확립된 지표). 초안의 "백업 지표"와
동일한 설계다. 새로 할 일은 없고, **파일럿으로 조기 판정하는 것**만 추가하면 된다(§7).

### 4.2 NAND

초안의 캐시 버퍼 분리 논지는 **레포에 이미 명문화되어 있다**
(`docs/project_context.md:75` — 셀 → 페이지 버퍼 → 핀의 2단계 구조).
초안의 기여는 그 관찰을 **논문의 claim으로 승격**시킨 것이지 새 발견이 아니다. 이 구분을
지켜야 한다 — 문서에 이미 있는 내용을 새 발견처럼 쓰면 지도교수 검토에서 바로 걸린다.

on-die ECC 비활성화(ECC-E)도 이미 프로토콜 전제로 문서화되어 있다
(`docs/project_context.md:99`). 데이터시트 확인만 남았다.

### 4.3 결정론 지터 — 초안에 없던 논문 소재

천장 BER이 **0.2462로 세 클럭에서 완전히 동일**하다. 클럭을 3배 올려도 취약 비트 집합의
비율이 불변이라는 뜻으로, 랜덤 지터 지배라면 0.5로 수렴해야 한다. 이건 초안이 다루지 않은
독립적인 관측이고, 단일 가우시안 모델의 부적합에 대한 직접 증거다.

논문에서의 위치: claim의 세 번째 문장 후보이자, "왜 우리는 BER 1e-12 외삽을 제시하지
않는가"에 대한 방어 근거. 리뷰어가 반드시 묻는 질문이므로 **미리 답을 준비한 상태**라는
점이 강점이다.

## 5. 디바이스 범위 — SRAM 우선순위 하향

초안은 SRAM 레퍼런스를 "없으면 NOR 데이터 전체 신뢰도가 흔들린다"고 최상위에 놓았다.
**과장이다.** 레포에는 이미 계측기 드리프트 방어가 3중으로 있다:

| 방어선 | 커버 범위 | 상태 |
|---|---|---|
| G0 루프백 (칩 없이 자기 배선 곡선) | FPGA 내부 경로 | 완료, σⱼ 29.1/29.2ps 기준선 확보 |
| 반복성 프로토콜 (5회) | 측정 노이즈 플로어 | 완료, ±0.61ps |
| 무마모 대조군 2개 (주기 재측정) | 장비 드리프트 + 시간축 | 설계 확정, 미착수 |

"60°C에서 마진이 줄었다 — DUT인가 계측기인가"라는 질문은 **온도 축에서 루프백을 다시
찍는 것**(신규 RTL 0줄, 점퍼만 꽂으면 됨)과 **무마모 대조군의 온도 응답**으로 대부분
닫힌다. SRAM이 추가로 주는 것은 "소켓·배선·패키지를 포함하되 마모가 없는 DUT"라는
한 조각뿐이다.

**결정: SRAM은 3순위. 온도 축 개통 후, 루프백+대조군으로 안 닫히는 잔여가 확인되면 추가.**
비동기 병렬 SRAM은 신규 인터페이스 RTL이 필요해서 "스윕 코드 재사용"이라는 초안의 비용
평가도 낙관적이다(SPI 시퀀서를 통째로 대체해야 한다).

DRAM 제외는 초안 판단대로 유지한다.

| | 데이터 출력 주체 | 마모→타이밍 마진 | 논문 내 역할 | 우선순위 |
|---|---|---|---|---|
| NOR (W25Q64) | 어레이 직결 | 연결 가설 (고클럭) | **주 실험** | 1 — 확보 완료 |
| NAND (W25N) | 캐시 버퍼 | 분리 예측 | **아키텍처 대조** | 2 — 조달 대기 |
| SRAM | — | 노화 없음 | 계측 레퍼런스 | 3 — 잔여 확인 후 |

## 6. Claim

초안의 3층 구조(발견 / 방법 / 검증)와 "정확도가 아니라 반복성·상대 민감도로 표현한다"는
3안 채택은 **레포의 기존 입장과 정확히 일치한다**(`docs/project_context.md:264` 원칙 4,
`README.md:69`의 한계 명시 절). 그대로 간다.

**Claim 초안 (수치 갱신판)**

> 플래시 메모리의 타이밍 마진이 노화 지표로 유효한지는 데이터 출력 경로의 아키텍처에
> 의해 결정된다. NOR(어레이 직결)에서는 고클럭 조건에서 마모와 상관하는 반면,
> NAND(캐시 버퍼 경유)에서는 분리되며 tR이 유효 지표가 된다. 이를 sub-ps 반복성
> (σ = 0.61ps)의 저비용 위상 스윕 계측으로 실증하고, NOR에서 이력 미상 칩의 누적 P/E를
> ±N% 오차로 블라인드 추정했다.

"저비용"과 "sub-ps 반복성"이 한 문장에 들어가는 것이 이 논문의 판매 포인트다 —
20만원짜리 COTS 플랫폼이 폭 재현성 0.61ps를 낸다는 사실 자체가 리뷰어에게 반직관적이다.

**블라인드 추정은 이미 사전 등록되어 있다**(`docs/project_context.md:202-209`) — 마모
담당자가 횟수를 숨기고, 정답은 사전 커밋. 사후 해석이 아니라는 점을 논문에서 명시할 수
있는 상태다. 이것이 가장 강한 카드라는 초안 판단에 동의한다.

**Fallback**: 마모-마진 상관이 없으면 → "타이밍 마진은 노화와 무관하며 시간 지표(tERASE, tR)만
유효하다"는 음성 결과 + 계측 방법론 논문. 등급은 내려가지만 성립한다. 파일럿(§7)이
이 분기를 조기에 판정한다.

### 6.1 초안이 놓친 것 — Baseline

초안 §8-1이 지적한 "비교 대상 없이 만들면 사후에 못 만든다"가 **현재 레포의 실제 구멍**이다.
지금 오라클 3종(Winbond 모델·golden model·루프백)은 전부 **디지털·논리 영역**이라, "우리
측정이 물리적으로 맞다"는 외부 기준이 없다. `README.md:147`의 고도화 축 7(스코프
correlation)이 그 자리다.

현실적 baseline 3종:
1. **데이터시트 스펙 타이밍** — 무료. W25Q64JV의 tCLQV 등과 측정 윈도우의 정합성.
2. **오실로스코프 아이 다이어그램** — 300~500MHz 스코프 필요. 절대 일치가 아니라 상관관계용
   (프로브 로딩이 측정 대상을 변형하므로).
3. **Fault Injection 자기 검증** — 알려진 지연 주입 → 복원 확인. RTL 미구현, 저비용.

3번은 지금 구현 계획에 넣을 수 있고, 1번은 즉시 가능하다. **2번(스코프)이 없으면 논문의
correlation 절이 비므로, 교수님께 요청할 장비 목록의 1순위는 스코프다** — 상위 FPGA 보드는
claim 증명에 필수가 아니지만(§3.5), correlation 부재는 claim의 신뢰도를 직접 깎는다.

## 7. 실행 순서 — 재작성

초안의 순서는 1번이 이미 완료되어 갱신이 필요하다. 그리고 **미구현 RTL이 마모 실험의
선행 조건**이라는 점이 초안에 빠져 있었다.

```
0. [완료] G0 루프백 · G2 브링업 · G3 클럭 사다리 · G4 반복성
   → 검증: valid=1 ×3클럭, σ_width = 0.61ps

1. P/E 사이클러 + op_timer(10ns) RTL 구현        [현재 TODO, 마모의 선행 조건]
   → 검증: 시뮬 회귀 PASS + 실칩 1섹터 100사이클 왕복, 소거 시간 로그 생성

2. 마모 파일럿 — 칩 1개(예비분), 1섹터, 0 → 10k    [claim 1문장의 생사 판정]
   → 측정: 25MHz(대조) + 75MHz(관측) 2점, 체크포인트 0/1k/3k/10k
   → 필수 대조: **0사이클 샴(sham) 체크포인트** — 마모 루프를 돌리되 사이클 수 0으로
     같은 시간·같은 전원 사이클을 거친 뒤 재측정. 이것이 마모 실험 조건에서의
     진짜 노이즈 플로어다 (0.61ps는 재장착·시간 드리프트를 포함하지 않은 EV 한 조각)
   → 검증: 75MHz 폭 변화가 샴 편차의 3배를 넘는가 / 소거 시간은 반드시 증가해야 함
   → 분기: 폭 반응 O → claim 원안 / X → §6 fallback 확정, 교수님과 저널 재조정

3. [1·2와 병렬] DUT 보드 — 히터·레벨 시프터·짧은 배선
   → 검증: 60°C 유지 ±2°C, 레벨 시프터 경유 3.3V 스윕이 25°C 기준값 재현

4. 온도·전압 축 + 루프백 온도 대조                 [계측기 드리프트 분리]
   → 검증: 루프백 폭의 온도 변화 ≪ DUT 폭의 온도 변화

5. G5 3조건 충족 → NOR 종단 마모 본실험
   → 전수 10개 신품 측정 · 노이즈 플로어(완료) · 블라인드 정답 사전 커밋

6. 교정 곡선(band) → 블라인드 추정 오차 ±N%

7. NAND — 조달 후. 아키텍처 대조, tR·RBER, read disturb
```

**2번이 새 1순위다.** 초안의 1순위(클럭 vs 폭)가 완료됐으므로, 다음으로 불확실성이 큰
게이트는 마모-마진 연결이다. 파일럿 비용은 칩 1개 + 며칠이고, 여기서 논문 골격이 확정된다.

10k 사이클을 먼저 찍는 이유: 인듀런스 스펙(10만 회)의 10%면 확립된 열화 지표(소거 시간)에는
반드시 신호가 나와야 하는 구간이다. **소거 시간마저 안 변하면 마모 프로토콜 자체가 잘못된
것**이므로, 이 파일럿은 마모 절차의 자기 검증도 겸한다.

> 마모는 이 프로젝트의 유일한 비가역 행위다(G5). 파일럿은 예비분 칩으로만, 섹터 1개로
> 한정한다 — 본실험 시료 배분을 건드리지 않는다.

- W25Q64JV — 소거·프로그램 시간 typ/max (마모 wall clock 산정용).

  wall clock ≈ 사이클수 × (tSE + tPP × 페이지수). 10k 파일럿의 소요 시간이 여기서 나온다
- UltraScale+ IDELAYE3 — 탭 2.5ps(TIME 모드, 원시 2.1~12ps)는 확인됨(UG571/UG974).

  유지되는지, (c) 탭 DNL/INL 교정 절차(code density test) 비용
- CMU SAFARI (Yu Cai, Onur Mutlu) FPGA 기반 NAND 특성 평가 플랫폼 — 선행 연구 직접 확인

- 학회 데드라인과 5학년 1학기 일정 정합
