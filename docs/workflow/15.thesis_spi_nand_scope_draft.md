## 1. 이 장이 답할 질문

NOR 에서 선 방법 — **소거(· 프로그램) 시간의 칩 안 비(닳은 영역 ÷ 안 닳은 영역)로 누적 P/E 를 구간으로 역산** — 이 구조가 다른 메모리
(셀 → 페이지 버퍼 → 핀의 2단계, on-die ECC 가 있는 SPI NAND)에서도 성립하나. 그리고 NOR 에는 없던 축 — **ECC 를 끈 raw 비트 에러 ·
ECC 여유** — 가 마모를 읽는 지표로 쓸 만한가. NOR 의 윈도우 폭 가설은 이미 기각됐으므로(`../project_context.md` §3), NAND 에서
윈도우 폭은 질문에 넣지 않는 것이 자연스럽다(버퍼 구조라 더 움직일 이유가 없다).

## 2. 선택지

공통 가정 — 장비 · PS SPI · µs 타이머 · 호스트 실행기 골격은 재사용. 칩은 W25N01KV 한 품번. 인일은 한영웅 1인 기준의 거친 추정이다.

| | (가) M2 에 넣지 않음 | (나) 최소 — 측정 가능성 장 | (다) 전면 — 마모 + 역산 |
|---|---|---|---|
| 논문 주장 | 「NAND 는 on-die ECC 때문에 측정 전제가 다르다 — 향후 과제」 한 문단 | 「같은 장비 · 같은 지표가 SPI NAND 에서도 잡히고 마모에 반응한다(또는 안 한다), raw 에러는 ECC 를 끄면 보인다」 — 존재 · 반응 주장, n 작음, 역산 없음 | 「수명 역산이 메모리 종류를 넘어 일반화된다」 — NAND 교정 곡선 · 등록 · 블라인드까지 |
| RTL | 없음 | **없음** — 윈도우 스윕을 하지 않으면 측정 경로(0x0B 고정 시퀀서)를 안 건드린다 | 선택. 윈도우를 재려면 페이지 읽기(13h) 뒤 버퍼 읽기로 시퀀서 개정 + 계약 수정안 |
| 펌웨어 | 없음 | NAND 입출력(ID · 보호 해제 · ECC-E · 상태 레지스터) · 불량 블록 표시 선(先)스캔 · 신품 전 블록 소거 시간 · 마모 루프 · ECC 끈 되읽기 비트 비교(페이지별 Fail Map) | (나) + 체크포인트 · 휴지 · 재개 · 블라인드 절차를 NOR 엔진 수준으로 |
| 호스트 · 분석 | 없음 | 캡처 파서 · CSV · 그림 3장(신품 분포 · 마모 곡선 · raw 에러 곡선) | (나) + 교정 · LOCO · 역산 모델 NAND 판 · S-5 등록 |
| 인일 (추정) | 약 0.5 | 약 12-17 (펌웨어 4-6 · 호스트 2-3 · 기판 · 첫 통전 2-3 · 분석 · 집필 3-5) | 약 30-45 |
| 보드 일 (추정) | 0 | 약 2-4 (신품 5칩 + 마모 1칩) | 약 15-30 (교정 5-6칩 · 블라인드 2-3칩 · 재측정) |
| 부품 · 비용 | 0 | 칩 5개 약 6.3만 원(10월 견적 개당 약 1.25만 원) + WSON-8 소켓 또는 변환 기판(**가격 확인 필요**) | 칩 10-15개 약 12.5-19만 원 + 소켓 · 기판. 20만 원 넘으면 학과장 승인 |
| 큰 위험 | 교수님 제안을 받지 않는 모양 | 보드 시간이 NOR M2 일(chip25 교정 · chip08 연장 · 욕조 v2)과 겹침 · 반응이 없으면 「음성 결과」 장 | M2 기한(미정) 안에 못 끝남 · NOR 블라인드 · 논문 초고가 밀림 |

**마모 시간 가정** (보드 일의 근거, 숫자는 전부 확인 필요한 데이터시트 값에 기댄다). 블록 1개 1사이클 = 소거 + 64페이지 × (2KB 적재 + 프로그램).
지금 PS SPI 는 약 2.6MHz 라 2KB 적재가 약 6.3ms — 블록당 약 0.42s, 60k 사이클이면 블록 하나에 약 7시간, 8블록 묶음이면 약 2.3일.
페이지 버퍼를 한 번 적재하고 프로그램 실행(10h)만 반복할 수 있거나 PS SPI 클럭을 올리면 블록당 약 20ms 대로 줄어 8블록 60k 가 약 3시간이다.
NOR 100k(7섹터)가 약 22시간이었던 것과 비교하면 내구 정격이 낮은(60k) 만큼 짧아질 여지가 크지만, **어느 쪽인지는 버퍼 재사용 확인에 달렸다.**

**공통 위험 · 주의**
- **ECC 를 껐다는 증거** — ECC-E 를 쓴 뒤 상태 레지스터를 되읽어 기록하고, 닳은 페이지를 켠 상태 · 끈 상태로 둘 다 읽어 차이를 남긴다. 안 하면 raw 에러 0 이 「안 닳음」 인지 「정정됨」 인지 가를 수 없다
- **불량 블록** — 공장 표시는 첫 소거 전에 읽어 저장해야 한다(소거하면 표시가 지워질 수 있음 — 확인 필요). 신품 전수 첫 명령이 소거가 되면 안 된다
- **전원 인가 보호** — BP 비트가 전부 1 로 켜져 와서 보호 해제 전엔 소거 · 프로그램이 조용히 무시될 수 있다. 소거 시간이 비정상으로 짧으면 이것부터 의심
- **소거 시간 분해능** — tBE 가 ms 단위라 NOR(수십 ms)보다 계단 수가 적으면 역산 구간이 거칠어진다. (나)의 신품 분포가 이 위험을 먼저 본다
- **주장의 한계** — W25N01KV 는 SLC 평면 SPI NAND 다. 교수님 의도가 최신 3D · MLC/TLC NAND 였다면 이 장은 취지가 다를 수 있다
- 코드 위치 — 펌웨어는 `ps/src/` 에 NAND 전용 파일로, RTL 을 건드리면 `fpga/rtl/flash/` 하위 분화는 소유자(팀원 A) 판단

## 3. 정하기 전에 확인할 것

**데이터시트 (전부 확인 필요 — 10월 메모의 값은 예비판 Rev A01(2022-01) 기준이라 정식판으로 다시 본다)**
- P/E 내구 정격(메모: 60,000) · 데이터 보존 조건
- ECC-E 의 위치 · 전원 인가 기본값(메모: 1) · 끌 때 다른 동작(BBM · 연속 읽기)이 바뀌는지
- tBE · tPP 의 typ · max(메모: 2 / 10ms · 250 / 700µs) — 역산의 분해능
- 프로그램 실행 뒤 데이터 버퍼 내용이 남는지(버퍼 재사용 → 마모 시간 수십 배 차이) · BUF 모드 · 연속 읽기 모드 기본값
- 블록 · 페이지 구조(1,024블록 × 64페이지 × 2KB + 스페어) · 공장 불량 블록 표시 위치 · 최대 불량 블록 수(메모: 20)
- 전원 인가 보호 비트 기본값(메모: 전부 1) · JEDEC ID 값 · 전원 전압(Pmod 3.3V 와 맞는 3V 판인지)
- 패키지(메모: WSON-8 8×6) 와 소켓 · 변환 기판 가격 · 배송 기간 · 다른 패키지 유무

**영웅님께**
1. M2 기한 · 데이터 마감 날짜(워크플로 14 TODO) — 이게 없으면 (나) · (다)의 가부를 못 정한다
2. NOR M2 일(느린 무리 교정 보강 · chip08 연장 · 욕조 v2 B4 · B5 · 초고)에 보드 A · B 를 며칠 쓰고, 남는 보드 일이 몇 일인가
3. 이 장의 주 지표를 소거 시간(방법의 일반화)에 두나, raw 비트 에러(PE 역량 · NAND 고유 축)에 두나

3. 지원 금액 · 집행 시점 (20만 원 초과분 학과장 승인 절차 포함)

## 4. 추천 (AI 제안 — 결정 아님)

**(나) 최소안을, M2 기한이 정해진 뒤 조건부로.** 이유:
- 논문의 중심은 NOR 의 역산과 블라인드 판정이고, 그것도 느린 무리 교정 보강이 남아 있다(chip08 불합격). (다)는 보드 시간에서 이 중심과 정면으로 부딪힌다
- (나)는 RTL 을 안 건드리고(윈도우 스윕 제외) 펌웨어 · 호스트만으로 되며, 교수님 제안에 「장비가 다른 메모리로 옮겨 가고 NAND 고유 축(ECC 끈 raw 에러)이 잡힌다」 는 실물로 답한다. 반응이 없어도 「버퍼 구조 · ECC 때문에 외부 관측이 어디까지 되나」 는 음성 결과로 장이 된다
- 비용이 작다 — 칩 5개 약 6.3만 원 + 소켓이라 부품을 먼저 사 두는 위험이 낮다(배송 기간이 일정의 앞쪽을 막지 않게)

진행 순서 제안: 데이터시트 정식판 확인 → 부품 주문 → 1칩 첫 통전(ID · 보호 해제 · ECC-E 되읽기 · 불량 블록 스캔) → 신품 5칩 소거 분포 → 1칩 0 → 60k 마모
(체크포인트마다 ECC 끈 raw 에러) → 그림 · 장 집필. **멈춤 조건**: M2 기한까지 6주가 안 남았거나 NOR 블라인드 · 교정이 밀리기 시작하면 (가)로 내린다.
첫 통전 · 신품 분포에서 계단이 보이고 보드가 남으면 그때 (다)로 넓힐지 다시 묻는다.
