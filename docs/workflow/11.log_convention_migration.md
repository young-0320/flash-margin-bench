## 이 작업의 경계 — 옮기고 지우기만 한다

전수조사는 **편집**이지 **재집필**이 아니다. 로그의 값은 그때 그 판단이 그 문장으로 남아
있다는 데 있고, 서식을 맞추려다 그걸 고쳐 쓰면 규약을 지키려다 로그를 잃는다.

| | 무엇 |
| --- | --- |
| **한다** | 골격 재배치 — `## 작업 내용` 안의 결정 문장을 `## 결정` 으로 올리고 경위를 `## 근거` 로 |
| | 폐지 절 제거 — `## 작업 내용` · `## 미결 의사결정` |
| | 폐지 필드 제거 — 머리말 `성격` · `작성` |
| | 로그 번호 링크화 — `로그 23` → `[로그 23](23.sweep_wrapper_and_uid_design.md)` |
| | ID 부여 — `## 결정` 에 `[D<번호>-n]`, `## 미결` 에 `[U<번호>-n]` |
| | 판별선 청소 — 절차·재현 절은 `workflow/`, 수치는 `results/` 로 넘기고 걷어낸다 |
| **안 한다** | 없던 근거를 지어내기 |
| | 결정을 다시 해석하기 |
| | 문장을 "더 낫게" 고쳐쓰기 — 어색해도 그때 쓴 문장 그대로 |
| | 결론 바꾸기 · 뒤집힌 결정을 조용히 정정하기 (추기로 붙일 뿐) |

**검증은 diff 로 한다.** 편당 diff 에서 **추가된 산문이 0줄**이어야 한다. 옮긴 문장은
`-` 와 `+` 에 같은 글자로 나타나고, 지운 것은 `-` 만 남는다. 새 문장이 `+` 에만 있으면
경계를 넘은 것이다. 예외는 셋뿐이다 — 절 제목, ID 대괄호, 근거 절 포인터(`— §2`).

## 결정이 없는 로그는 남긴다

옛 로그 중에는 "무엇을 했다"만 있고 "무엇을 정했다"가 문장으로 없는 것이 있다. 그러면
`## 결정` 을 채우려면 읽고 **추론**해야 하는데, 그게 위 경계의 입구다.

**추론이 필요하면 채우지 않고 남긴다.** 그 편은 골격만 세워 두고 `## 결정` 은 비운 채
아래 「보류 목록」에 적는다. 단계가 끝나면 한영웅에게 한꺼번에 넘겨 답을 받고 반영한다.
혼자 판단해서 채우고 나중에 확인받지 않는다 — 틀린 결정이 로그에 박히면 그 뒤로
그것이 정본이 된다.

## 한 편을 옮기는 절차

1. **읽는다** — 전문. 골격 재배치는 본문을 알아야 한다
2. **결정을 찾는다** — 이미 문장으로 있는 것만. 없으면 「보류 목록」으로 보내고 다음 편
3. **골격을 세운다** — `docs/log/FORMAT.md` 「골격」 그대로. 머리말 → 결정 → 근거 →
   (산출물) → 미결
4. **ID 를 단다** — `## 결정` 은 `[D<번호>-1]` 부터, `## 미결` 은 `[U<번호>-1]` 부터
5. **검사한다**

   ```bash
   python3 .claude/skills/log/check.py docs/log/young/<파일>
   ```

6. **diff 를 본다** — 추가된 산문이 0줄인지
7. 다음 편

## 단계를 닫을 때

- 그 단계 전편이 `check.py` 통과
- 「보류 목록」을 한영웅에게 넘기고 답을 받아 반영
- 커밋 — **git 이 진행 상태의 정본이다**
- 컨텍스트를 새로 하고 다음 단계

## 컨텍스트가 끊겼을 때 복귀

기억이 아니라 검사기로 복구한다. 통과한 편이 끝난 편이다.

```bash
for f in docs/log/young/*.md; do
  python3 .claude/skills/log/check.py "$f" >/dev/null 2>&1 || echo "남음: $f"
done
```

이 파일과 `docs/log/FORMAT.md` 를 읽으면 나머지 맥락은 재현된다.
