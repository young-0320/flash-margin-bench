## 결과 — 통과

σ_j = 11 ps(실측 상한) 기준:

| θ | σ_width @ N=112 | @ N=100 | 규칙 한계 |
| - | --------------- | ------- | --------- |
| 10⁻² | **0.162 ps** | 0.17 ps | 7.9 ps |
| 10⁻³ | **0.34 ps** | 0.35 ps | 7.9 ps |
| 10⁻⁴ | **1.35 ps** | 1.38 ps | 7.9 ps |

세 θ 모두 한계의 1/6 이하이며 N=100 대비 전 구간 소폭 개선. **N=112 채택에 통계적 손해
없음.**

## 부기 두 가지

**① 이 규칙은 N 선택을 구속하지 않는다.** 최악 조합(N=64, σ_j=100ps)에서도 1.13 ps로
통과한다. N의 실질 하한을 정하는 것은 θ=10⁻⁴의 유효 조건 `N × B × θ ≥ 20` → N ≥ 100이다.

**② 실측 반복성이 통계 예측의 약 3.6배다.** 시뮬레이션(이항 통계만)이 0.17 ps인데 실측
반복성(G4, n=5)은 0.61 ps다. 반복성의 대부분이 통계 잡음이 아니라 계통 요인임을 **시사**
한다 — 확정은 별도 실험(N=112 vs 448)의 몫. 상세는 로그 17 §4.3.
