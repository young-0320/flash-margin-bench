# chip16_loco_2026-10 — 설정 65°C 칩(chip16)을 넣은 모의 블라인드(LOCO, v4)

> 수치와 표만 둔다. 해석은 [`../wear/wear_temperature_chip16.md`](../wear/wear_temperature_chip16.md) §4 · §5.

- **무엇**: v4 등록 설정(눈금 ratio · R 은 σ_r 유도 · 경계 40ms · ρ 등록값)의 LOCO(p50 관측)를 교정 표 9장 — 등록 교정 8칩(chip01·02·03·04·07·09·15·18) +
  chip16 의 `_64C` 곡선 — 으로 돌린 결과. chip17 때(`chip17_loco_2026-10.md`)와 같은 두 가지가 한 번에 나온다:
  ① **chip16 을 뺀 차례** = 교정은 상온 8칩 그대로(v4)이고 관측은 설정 65°C 칩 — 상온 모델이 이 칩을 맞히는가 (외부 검증)
  ② **상온 칩을 뺀 차례** = chip16 이 교정에 들어간 경우 — 넣으면 상온 칩 LOCO 가 어떻게 되는가
- **입력**: 관측은 구간별 p50(섹터 7개, LOCO 기본). chip16 의 관측은 마모 중 A 행(센서 60 - 67°C 에서 잰 값)
- **파일**: [`chip16_loco_2026-10.txt`](chip16_loco_2026-10.txt) — `wear_inverse.py --loco` 출력 그대로(106점). 기준선(8칩 · 94점)은 `inverse_v4_eval_2026-10.md` §2 의 p50 행과 같다(75 · 91 / 94)
- **교정 표 원본**: `wear_curves/wear_curves_chip{01,03,04,07,09}_2026-09.csv` · `_chip{02,15,18}_2026-10.csv` · `wear_curves/wear_curves_chip16_64C_2026-10.csv`.
  교정 폴더는 건드리지 않았다 — 임시 폴더에 복사해 glob 을 맞췄다(재현 명령)
