## 재현

```bash
uv run python host/run/run_wear.py accept --chip chip06 --to 100000                                   # 12k → 100k (10/11, 보드 A)
uv run python host/run/run_wear.py accept --chip chip06 --to 200000 --checkpoints 110000,120000,130000,140000,150000,160000,170000,180000,190000,200000   # 10/12

```

- §1 은 `pe_end.py` 가 세션 폴더 `checkpoints.csv` · `.analysis.json` 에서 만든 CSV 그대로이고, 12k 개봉 prep 5행과 20k · 150k 비고만 손으로 넣었다(승격 때
  `--overwrite` 로 비고를 살려 합친다). §2 의 전환 구간 · 높이는 S-1 §15 H3 추정법(최대 상승 두 구간의 중점을 문턱으로, 전환 구간 ±2-3k 의 A 행을 갈라 두 수준
  중앙값 차) — 일회성 집계라 스크립트는 리포에 없다
