## 결론

**chip14 는 chip10 과 같은 W25Q64JV 이고, 둘이 같은 모양으로 늙었다 — 교정 8칩(전부 FV)과 다른 모양이다.** 소거 시간은 계단 없이 꾸준히 늘어 100k 에
신품의 2.65배(chip10 2.55), 섹터 7개가 모두 84ms 를 넘고도(39k - 59k) 계단이 오지 않았다 — FV 빠른 무리는 84ms 뒤에 1.2배 계단이 왔다(H6 ①).
프로그램은 늦게 조금 올라 100k 에 1.03 - 1.05배(chip10 1.11). 폭은 12점 중 11점이 1,000 사이클 대비 3σ 안이고 90k 한 점이 1.4ps 넘었는데, 그 점은
창 위치가 6스텝 움직인 자리라 마모보다 장착 쪽이다. FV 교정으로 돌린 현장 역산은 100k 를 59 - 60k 로 봤다(95% 상한에 걸림 — chip10 은 밖).
chip10 때 「한 칩이라 비교 보류」 였던 것이 **두 칩**이 되어, 「JV 세대는 FV 와 다르게 늙는다(계단 없음 · 배율 낮음)」 를 n=2 로 말할 수 있다.
UID 앞바이트 `DF` 가 JV 를 가리킨다는 것도 둘로 확인됐다(FV 전부 `D1 6x`). 날짜 코드 `1749` 는 「1430 이후」 예측대로지만 chip10(`1850`)과 같은 로트는 아니다.

## 1. 마진 — 12점 중 11점이 3σ 안

25MHz 폭 @1e-2 는 38,705.6 - 38,754.1ps. 체크포인트 100 이 없어(스윕 실패) 1,000 을 기준으로 삼으면 −43.4 - +5.1ps 다. 90k 의 −43.4ps 가 42ps 를
1.4ps 넘고 100k 는 −27.6 으로 돌아왔다. 세션 로그의 창 위치가 답을 준다 — 1k - 70k 는 −657 - −656 으로 1스텝 안인데 80k −658 · **90k −662** · 100k −659 로
뒤 세 점이 움직였고, 가장 많이 움직인 90k(6스텝 · 95ps)가 폭이 가장 좁은 점이다. 끊김 없는 한 세션(`1791204058`) 안이지만 창이 옮겨진 것은 접촉 ·
장착 쪽 신호이지 마모 신호가 아니다(chip07 의 10/2 계측 사건과 같은 읽기). H1′ 은 참으로 읽는다. 이 칩의 폭 약 38,740ps 는 chip10(약 38,850)처럼 FV 칩(39,300 - 39,800)보다 낮다 — JV 의 창 폭이 좁은 것인지
장착인지는 두 칩 다 같은 보드가 아니라 가르지 못한다.

## 2. 소거 — 84ms 를 넘어도 계단이 없다

섹터 중앙값이 1k 44.5 → 10k 59.6 → 50k 85.7 → 100k 96.2ms 로 늘었다. 10k 당 상승이 처음 1.5ms 에서 뒤로 갈수록 작아져(80k 이후 10k 당 1 - 2ms) chip10 의
「85 - 87ms 근처 포화」 가설과 같은 방향이지만, chip14 는 96ms 까지 갔으므로 포화 자리는 칩마다 다르다. **FV 빠른 무리의 계단 조건(섹터 1k 구간 중앙값
84ms)을 7섹터 모두 39k - 59k 에 만족했는데, 100k 까지 1.2배 계단이 어느 섹터에도 없다**(최대 점프 1.06 - 1.12, 전부 1k - 29k). chip10 은 84ms 에 겨우 닿아
「판정 밖」 이었는데 chip14 가 그 너머를 보여 줬다 — H6 는 FV 의 규칙이지 JV 의 규칙이 아니다.

배율로는 100k 2.65(chip10 2.55)로 FV 빠른 무리(2.60 - 4.34)의 아래쪽 끝, 느린 무리(1.46 - 1.68) 위다. 신품 소거 36.3ms(chip10 33.0)는 40ms 경계로 빠른
무리지만 FV 빠른 칩(26.0 - 33.7)보다 느린 쪽 — 두 JV 가 FV 의 두 무리 사이 틈(34 - 47ms)에 있다.

## 3. 프로그램 — 작지만 올랐다

섹터 중앙값 5.93(1k) → 5.87(10k) → 5.94(50k) → 6.12ms(100k), 100k/1k 1.03, 섹터별 1.02 - 1.06. chip10(1.11, 섹터별 1.08 - 1.16)보다 작지만 같은 모양(늦게
오름)이다. 신품 프로그램 5.9ms 는 FV(6.5 - 7.0)보다 빠르다 — JV 의 프로그램 알고리즘이 다른 것으로 보인다(가설).

## 4. 모델에 대해 — 교정 밖 · 외부 검증점

v4 교정은 FV 8칩이다. JV 둘을 넣지 않는다([U48-22] · [D48-105]). 현장 역산(100k 뒤 newchip, FV 빠른 무리 교정)은 chip10 이 54 - 55k(95% 밖), chip14 가
59 - 60k(68% 30 - 85k · 95% 23 - 100k, 정답이 95% 상한 끝)다 — **두 JV 모두 상온 FV 모델이 사용량을 약 0.6배로 낮게 본다.** 중고 판별에서는 남은 수명을
부풀리는 방향이다. 대조군 전제는 원격 · 기준 섹터 1.03 으로 성립하는데, 근접 대조군 7-13 이 1.10 으로 FV 종단 칩(0.98 - 1.02) · chip10(0.98)보다 높다 —
한 번 측정이라 「근접 교란」 이라 말하지 않고 수치로 둔다(Adafruit JV 가 오면 다시 본다). 두 JV 의 뜻은 「같은 품번 W25Q64 라도 세대(FV/JV)가 다르면 상온 모델이 틀린다」 는
M2 의 적용 범위 문장이고, 모델 적용 범위는 **「W25Q64FV, 날짜 코드 1309 - 1551」** 로 적는다. 「모른다」 고 말하는 장치(M3)의 첫 지문 후보가 신품
소거 틈(34 - 47ms) · UID `DF` · 프로그램 5.9ms 다.
