## Ⅳ. 결과 및 성과

결과는 계측기 → 신품 → 마모 → 모델 → 블라인드 → 온도 순으로 보고한다. 마모 가설은 해당 데이터를 보기 전에 실험 사양서(S-1 §15)에 날짜와 함께 등록했고, 결과를 본 뒤 내린 판단은 "사후 처리"로 표시했다. 사전 기준에 떨어진 항목도 기준을 바꾸지 않고 그대로 적었다.

### 1. 계측기 검증

"마진이 변하지 않았다"는 결과는 계측기가 그 변화를 잡을 만큼 정밀할 때만 의미가 있다. 실제 칩의 값을 확정하기 전에 계측기를 네 단계로 검증했다.

**표 Ⅳ-1. 계측기 검증 4단계**

| 단계 | 조건 | 결과 |
|---|---|---|
| ① 알고리즘 | 몬테카를로 4,000회, 지터 σⱼ 11ps, N = 64-448 | N = 112 의 폭 추정 표준편차 0.162ps(θ = 10⁻²) — 사전 규칙 한계 7.9ps 의 1/6 이하[^mc] |
| ② FPGA 단독 | 칩 없이 Pmod 루프백, 25MHz, 2,520스텝 | 욕조 곡선 완주, 폭 34,693ps[^lb] |
| ③ 같은 칩 반복 | chip01 5회, 재장착 없음 (7월, N = 100) | 39,737.3 ± 0.61ps[^rep5] |
| ④ 재장착 반복 | chip10 3회, 매번 뺐다 다시 꽂음 | σ 13.86ps → 판정선 3σ = 42ps[^ns6] |

몬테카를로에서 폭 추정 오차는 N = 64 에서도 한계 안이었으므로, N 의 하한은 θ = 10⁻⁴ 판정이 성립하는 조건(N × 2,048비트 × θ ≥ 20 → N ≥ 100)이 정했고 여유를 두어 112 로 했다[^mc]. ③과 ④를 비교하면 칩을 꽂은 채로는 0.61ps, 뺐다 꽂으면 13.86ps 로 20배 넘게 커진다. 오차의 대부분은 장비가 아니라 칩과 핀헤더의 접촉에서 온다. 그래서 마모 전후 비교는 칩을 빼지 않은 첫 체크포인트(x = 100)를 기준으로 하고, 판정선은 보수적으로 재장착 3σ(42ps)를 썼다.

계측기가 믿을 만하다는 것은 이상이 없다는 뜻이 아니라, 이상을 칩의 변화로 착각하지 않는다는 뜻이다. 두 사례가 있었다. 앵커 chip02 가 기준 대비 −302.8ps 로 판정선의 21배 밖에 나갔을 때, 같은 세션에서 재장착을 끼고 잰 chip10 3점은 27ps 안에 있었다. 측정계가 아니라 chip02 조립체의 고장이었다[^ns6]. chip07 은 마모 70k 직전 폭이 +590ps 뛰었는데, 스윕 원점(−714 → −685 스텝)과 오류 버스트성 F(0.46 → 1.06-2.77)가 함께 바뀌고 클럭마다 이동 방향이 달랐다. 셀 노화라면 방향이 한쪽이어야 하므로 배선 접촉 사건으로 판정했고, 선을 다시 누르자 원점과 F 가 원래 값으로 돌아왔다[^c07].

### 2. 신품 전수 측정

신품 16개 라벨 중 15개를 측정했다(원 배치 9 + 추가 구매 6). chip05 는 네 번 모두 JEDEC ID 가 `FF FF FF` 로 읽혀 제외했다[^ns7].

**표 Ⅳ-2. 신품 15칩 요약**

| 항목 | 결과 |
|---|---|
| 25MHz 유효 창 폭 | 38,729.6-39,801.5ps — 40ns 주기의 96.8-99.5%[^ns1] |
| 출고 blank (전역에서 0 으로 굳은 비트) | 판정 가능한 13칩 모두 0비트[^ns1] |
| 소거 시간 (섹터 0-127 중앙값) | 빠른 무리 10칩 25.7-36.3ms · 느린 무리 5칩 47.0-51.1ms[^ns1] |
| 칩 간 산포 대 재장착 산포 | σ_between 333.9ps(n = 9) > 3σ_repeat 41.6ps — 개체 차이가 측정 잡음과 분해됨[^ns6] |

**소거 시간은 신품끼리 두 배 다르다.** 같은 품번의 신품이 25.7-51.1ms 로 퍼졌고 두 무리로 갈려, 경계를 두 무리 사이 40ms 로 두었다[^d40]. 마모 탓이 아니다 — P/E 5회의 chip02(27.2ms)가 1회의 chip03(51.1ms)보다 빠르다[^nsI1]. "몇 ms 이상이면 노화"라는 절대 기준은 성립하지 않으므로 마모는 각 칩의 신품값 대비로만 읽는다. Ⅱ.2 에서 제기한 개체 차이 문제의 실측 근거다.

**마진은 개체 간에 거의 같다.** 소거 시간이 두 배 다른 chip02 와 chip03 의 창 폭 차이는 22.6ps(0.057%)였다[^nsI1]. 두 지표가 독립이라는 첫 증거다. 예외는 UID 앞바이트가 `DF` 인 chip10·chip14 로, 폭이 나머지보다 약 900ps 낮고 소거 시간이 두 무리 사이(33.0·36.3ms)에 있다[^ns1]. 다른 로트일 가능성이 있으나 확인하지 못해 교정과 블라인드에 쓰지 않았다.

**타이밍 마진은 정격 수명의 1-3배까지 움직이지 않았다.** 25MHz 창 폭은 다섯 칩 모두 재장착 3σ(42ps) 안이었다. chip01 은 정격의 3배인 30만 회에서도 신품 대비 +15.5ps 였고, 방향도 좁아지는 쪽이 아니었다[^p01]. 접근 시간 여유가 가장 작은 75MHz 에서도 마모 전후 차이는 chip03 +8.7ps, chip04 −2.0ps 로 위상 한 스텝(15.9ps) 안이었다[^c03][^c04]. 사전 등록 가설 H1·H1′ 은 참이다. 단 chip07 은 처음 10k 동안 −59ps 까지 내려가 숫자로는 기준을 넘었고, 이후 40k 동안 움직이지 않아 장착 뒤 안정화로 판단했다. 결과를 본 뒤의 판단이라 사후 처리로 표시한다[^c07].

마진이 움직이지 않는 데는 구조적 이유가 있다. 출력 엣지는 클럭에 동기된 출력 레지스터가 만들고, 셀이 닳아 늘어난 어레이 접근 시간은 40ns 주기 안의 여유에 묻혀 엣지에 닿지 못한다(Ⅲ.1). 중간계획서의 전제("마진은 에러보다 먼저 줄어드는 선행 지표")는 이 칩·이 조건에서 성립하지 않았고, 이것이 수명 지표를 소거 시간으로 바꾼 근거다.

### 4. 수명 역산 모델 검증

**① 교정 칩끼리의 모의 블라인드(LOCO).** 교정 칩 하나를 빼고 나머지로 그 칩의 체크포인트 12점을 맞히기를 5칩에 돌아가며 했다(58점). 68% 구간이라면 정답을 약 68% 품어야 정직하다.

R 은 처음 교정 4칩의 두 쌍에서 규칙으로 2.0 을 냈다. chip09 를 더하자 같은 규칙이 3.8 을 냈으나, 교정 곡선 혼합이 이미 빠른 무리 안 2.9배 속도 범위를 품고 있어 r 을 얹으면 같은 산포를 두 번 센다는 구조 결함이 드러났다. 그래서 2.0 으로 돌아갔고, 이때 LOCO 포함률이 값 선택에 쓰였다. 블라인드 정답을 열기 전의 결정이다[^d60]. 무리별로는 느린 무리가 68% 구간에 21/22, 빠른 무리가 21/36 이었다[^l17]. 빠른 무리의 빗나감에는 가장 느리게 늙는 chip09 의 3k-50k 6점이 들어 있고, 계단 이후(약 5만 회 이상)는 착지 높이가 칩마다 달라 MAP 이 낮게 치우치고 범위만 준다[^l17][^c15].

**② 합성 복원.** 모델 가정대로 만든 가짜 칩 500개를 맞혀, 모델이 말한 확률과 실제로 정답이 구간에 든 비율을 비교했다(판정용 설정, 교정 5칩 · R 2.0)[^syn]. 블라인드·현장과 같은 "처음 보는 칩" 조건에서 prep 5회의 68%·95% 포함률은 66%·91%, prep 1회는 68%·90% 로 명목에 가깝다. 반면 prep 5회를 독립 관측으로 곱하는 우도는 53%·81% 로 과신했다. 이 결과로 블라인드 직전에 넣으려던 우도 수정을 되돌렸다 — prep 을 반복하면 측정 잡음은 줄지만 칩 사이 곡선 차이는 줄지 않기 때문이다[^l48s24]. 진단 시간은 prep 1회 약 40초, 5회 약 3-4분이다[^mat14].

### 5. 블라인드 테스트 (chip06)

박지민이 chip06 의 섹터 0-6 을 1,000-80,000 회 안에서 정한 횟수만큼 마모시키고 정답을 칩 내부 tally 에 남겼다. 추정 측은 횟수를 모른 채 마모 종료 24시간 안에 prep 5회로 측정했고, 판정용 추정을 미리 지정한 뒤 모든 추정을 tally 를 읽기 전에 커밋했다. 기준 섹터 소거 중앙값은 25.3ms(빠른 무리), 마모 섹터 35개의 신품 대비 배율 중앙값은 1.63 이었다[^bd].

**교정 칩 하나가 판정을 바꿨다.** 빨리 늙는 칩(chip01·04)만 알던 v1 은 구간을 1.1만에서 닫아 정답을 68% 밖에 두었고, 천천히 늙는 빠른 칩 chip09 를 더한 v2 는 구간이 1.9만까지 열리며 정답을 품었다(그림 Ⅳ-4). v1 이 세 기준을 모두 통과한 것은 운이었고, 넓어진 v2 의 구간이 정직한 불확실성이었다. MAP 은 정답의 약 0.6배로 낮게 치우쳤는데 사후분포가 "느리게 늙는 칩" 쪽으로 꼬리가 길기 때문이며, 이 칩에서는 사후 중앙값(약 1.2만)이 더 가까웠다[^bi]. ③ 의 1만 기준은 교정 칩이 무리당 둘이던 때 정한 값이지만 바꾸지 않고 불통과로 보고한다.

이 결과의 주장은 "블라인드 1칩에서 정답이 두 구간 안, 분포 중앙에 있었다"까지다. 3인 팀이라 완전한 블라인드는 아니며, 정답을 칩에 봉인하고 추정을 먼저 커밋하는 순서로 보완했다. v2 의 R 은 R 3.8 결과를 본 뒤(정답 전) 고쳤고, 버린 설정도 정답을 품었다[^bi].

### 6. 온도 축 (chip17, 칩 위 65°C)

chip17(빠른 무리, 추가 구매 로트)을 칩 위 약 65°C 에서 10만 회 마모시켰다. 계획은 80°C 였으나 히터 출력 한계로 65°C 가 평형점이 되었고, 마모 시간 평균 65.22°C, 그 97.2% 가 63-67°C 였다[^tc]. 온도 칩용 가설은 따로 세우지 않고 상온 종단 칩의 기준을 그대로 적용했다.

마진은 고온 이력에서도 움직이지 않았다. 다만 런 동안 온도가 일정했으므로 계측기가 온도 변화에 반응하는지(양성 대조)는 이 런으로 보이지 못한다. 소거 배율은 상온 세 칩보다 낮았지만, 상온 세 칩끼리도 속도가 2.9배 다르고 비교 칩이 셋뿐이라 65°C 효과는 개체·로트 차이와 구별되지 않는다[^t17]. 고온에서 포획 전자가 열로 빠져나가고 프로그램의 열전자 주입 효율이 떨어진다면 "소거는 덜 늘고 프로그램은 일찍 올랐다"는 두 관찰이 함께 설명되지만, 이는 가설로 남긴다.

실용상 중요한 것은 마지막 행이다. 상온 모델(v2)은 이 칩의 사용량을 모든 점에서 정답의 0.15-0.35배로 낮게 봤다(100k → MAP 34-35k). 중고 칩 판정에서 남은 수명을 부풀리는 위험한 방향이므로, 모델의 적용 범위를 "상온 사용 이력"으로 두고 그 경계를 데이터로 그었다. chip17 을 교정에 넣으면 상온 빠른 무리의 68% 적중은 그대로(21/36)이고 구간 폭만 44,000 에서 49,500 으로 넓어져, 교정이 아니라 외부 검증 점으로 쓴다[^l17].
