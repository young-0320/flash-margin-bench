## 1. 왜 NOR 플래시인가 — 문제 제기 (1분) · 창의성

**메시지**: 안전이 걸린 시스템의 부팅 코드를 쥔 NOR 은 「튼튼하다」 고 알려져 연구가 드물고, 그래서 늙어도 PASS 로 통과한다.

본문:
- NOR 의 자리: 자동차 ECU · 산업 제어기 · 의료 장비의 **부팅 코드 · 펌웨어** 저장 — 바이트 단위 실행(XIP), 비트 에러 거의 없음, 정격 내구 10만 회 · 85°C
- 선행 연구: 재활용 플래시 판별은 NAND 중심(Sakib 외, *Cryptography* 2018). 저자들 스스로 **「a very few works on the detection of recycled Flash memory」**. 답은 「썼다 / 안 썼다」 뿐
- 현장의 함정 두 가지:
  1. 정격 3배(30만 회)를 쓴 칩도 기능 검사는 PASS
  2. 선행 방식은 「같은 품번이면 신품 소거 시간이 같다」 는 전제 — 저희가 같은 품번 **신품 31칩**을 재니 **24.5 ~ 53.4ms, 두 배 차이**. 신품 느린 칩(51.1ms)이 1,000회 쓴 빠른 칩(46.5ms)보다 느리다
- `[출처 필요]` 「극한 환경에서 NOR 플래시 고장 보고」 — 리포에 출처가 없다. 논문 · 리콜 사례를 하나 찾아 각주로 달거나, 이 문장을 빼고 위 1 · 2 로만 간다

노트: PASS/FAIL 표(전부 PASS) 한 장 + 신품 31칩 소거 시간 분포에 「1,000회 쓴 chip04」 점 하나를 찍어 신품 분포 안에 들어가는 그림.

## 3. 발상 — 마진을 피코초로 직접 잰다, 그런데 (1분 30초) · 창의성 · 난이도

**메시지**: 「에러가 나기를 기다리지 않고 장비가 경계까지 다가가 여유를 잰다」 는 발상은 맞았고, 「마모가 그 여유를 줄인다」 는 가설은 데이터가 기각했다.

본문:
- 방법: FPGA MMCM 미세 위상 제어로 읽기 샘플 클럭을 **Δφ = 15.873ps** 씩 **2,520스텝** 밀며, 스텝마다 PRBS15 를 112회 × 2,048비트 읽어 BER → 욕조 곡선 → 양 벽 교점의 폭(θ = 10⁻²)
- 자의 정밀도: 같은 칩 5회 반복 **±0.61ps** · 재장착 3회 **σ = 13.86ps → 판정선 3σ = 42ps** · 신품 폭 39,737ps (40ns 주기의 99.3%)
- 가설: 셀이 닳으면 이 창이 **에러 전부터** 좁아질 것 → 창 폭 = 남은 수명
- 결과: **30만 회까지 +15.5ps, 10만 회 칩 9개 전부 42ps 안** — 기각
- 왜: 출력 핀의 엣지는 SCLK 에 맞춰 도는 **출력 레지스터**가 만든다. 셀은 센스 앰프에 「전류 있음/없음」 만 주므로 셀이 늙어도 시계는 안 늙는다
- 그래서 처음부터 보조로 같이 기록하던 **소거 · 프로그램 시간**으로 지표를 옮겼다 (사전 등록 때 이중화해 둔 덕)

노트: 「가설이 틀렸다는 것이 첫 결과」 를 숨기지 않는다. 파일럿 29,600회 시점에 「정격 안에서는 안 움직인다(H1)」 를 먼저 적었고 나머지 9칩이 그대로 나왔다.

## 5. P/E 마모의 원리 (1분) · 구현

**메시지**: 소거 시간은 산화막 흠집의 계수기다 — 그래서 첫 사이클부터 단조 증가하고, 이력을 되짚을 수 있다.

본문 (그림 중심):
- 소거 = FN 터널링. 칩 내부는 **펄스 → 검증 읽기 → 부족하면 다시 펄스** 루프. 마모로 산화막에 트랩이 생겨 전자가 박히면 전계가 깎여 같은 펄스로 빠지는 양이 줄고 **펄스 수가 는다** → 소거 시간 증가 (첫 사이클부터, 단조)
- 프로그램 = 핫 일렉트론 주입. 벽을 *넘기는* 것이라 벽 *안의* 흠집에 덜 민감 → 계면 준위가 쌓인 **한참 뒤에야** 는다
- 벤치 설계: 4KB 섹터 **0~6 (7섹터)** 만 프로그램(0x00) · 소거 반복, **섹터 32~127 은 손대지 않는 기준 섹터**. 사이클마다 섹터별 소거 · 프로그램 시간을 로그(A 행, 칩당 70만 행). 체크포인트(13점)마다 위상 스윕 + prep(PRBS) 측정
- 데이터시트(W25Q64FV): 섹터 소거 typ 45~60ms · max 400ms · 정격 10만 회

- 해석: 「고온이면 더 닳는다」 는 직관은 소거 시간에는 거꾸로 갈 수 있다 — 갇힌 전하가 열로 빠져 소거가 덜 늦어진다(chip17 이 상온보다 느리게 늙은 것과 맞음). 프로그램은 빠른 무리에서 불변 · 느린 무리에서 상승 — 5장의 원리(핫 일렉트론은 계면 준위가 쌓여야) 그대로
- **표본 부족을 먼저 말한다**: 무리당 1~2칩, 칩 온도는 센서 자리 온도. 모델에 온도 축을 넣지 않고 고온 이력 칩에는 **범위(95%)로 답한다**

노트: chip16 은 온도 로그가 히터 상태와 맞지 않아(꺼진 채 3시간 67°C) 「65°C 이력」 이라 쓰지 않는다 — 한계 3 의 실제 사례.

## 13. 한계 세 가지 (1분) · 난이도 · 구현

**메시지**: 한계는 셋이고, 셋 다 「어디까지 모르는지」 를 숫자로 말할 수 있다.

세 칸 (번호 연두 배경):

1. **적용 범위가 한 품번(W25Q64FV)이다.** 교정 9칩 전부 FV. 같은 패키지의 JV 는 신품 12칩을 쟀지만 교정 곡선이 없고, 마모시킨 JV 두 칩(chip10 · 14)은 어느 무리 곡선과도 맞지 않아 **「판정 보류」**. FV 안에서도 느린 신품 5칩 중 2칩(chip12 · 21)은 빠른 속도로 늙어 상온 모델이 68% 0/12 로 전부 틀린다 — 개봉 전 한 점으로는 못 가른다
2. **욕조 곡선(타이밍 마진)을 수명 지표로 쓰지 못했다.** 1차 이유는 물리 — 마진이 30만 회까지 안 움직였다(출력 레지스터가 엣지를 정함). 2차는 장비 — 벽 천이가 위상 해상도 **Δφ = 15.87ps** 보다 가팔라 한 스텝에 BER 이 10⁻⁴ → 5×10⁻² 로 뛰고, 그래서 **BER 10⁻⁴ 아래(욕조 바닥)와 10⁻¹² 외삽 폭을 볼 수 없었다** (MMCM VCO 고정, 어느 클럭으로 올려도 같음)
3. **칩 내부 온도를 모른다.** 센서가 구리판 위에 있어 **구리판 → 모듈 PCB(FR4) → 패키지** 사이의 온도 차를 재지 않았다(센서 · 히터 배치 기록도 없음). 다이 ↔ 패키지 표면 차이는 자기 발열 약 65mW 로 1°C 미만(계산, `[확인 필요: 데이터시트 ICC · SOIC-8 ψ_JT]`)이라 문제는 판 ↔ 패키지 쪽이다. 85°C 근처 10°C 오차는 Arrhenius 가속 배율 약 2배에 해당한다

노트: 1 은 「모르는 칩에 답하지 않는다」 가 기능으로 들어 있다는 것과 같이 말한다. 2 는 「보드가 나빠서」 가 아니라 「물리가 그렇고, 자의 눈금도 거기까지」 두 층으로. 3 은 정직하게 「이만큼 모른다」 로.

## 14. 극복 방안 (1분) · 난이도 · 발표

**메시지**: 두 한계는 측정으로 닫을 수 있고, 얼마나 더 재면 되는지도 안다.

좌 — **다른 IC 로 교정 곡선 만들기 (한계 1)**:
- 학습 곡선이 답을 준다: 빠른 무리는 **교정 3칩에서 포화** (1 → 3칩: 68% 적중 27 → 73% · 95% 46 → 90% · 배율 오차 0.51 → 0.37, 3 → 5칩은 표준오차 안). 즉 **품번 하나 = 무리당 3칩 × 10만 회(칩당 약 1~2일 무인)** 로 교정 가능
- 첫 대상은 이미 신품 12칩을 쟀고 `DF` · `D16x` · `CA` 세 UID 꼴로 갈리는 **W25Q64JV** → FV 교정 절차를 그대로 돌린다
- 느린 신품의 두 종류(chip12 · 21 형)는 개봉 때 짧은 추가 마모 Δx 로 **노화 기울기**(첫 1k 에 1.22 대 1.04~1.09)를 재서 가른다 — v4.4

우 — **다른 지표 더하기 (한계 2 · 고마모 상한)**:
- 소거 시간 한 지표의 정보 한계: 빠른 무리는 160k 뒤 평탄 · 정답 80k 이상에서 0.84 과소추정 — 어떤 통계 처리로도 안 풀렸고(후보 7개 비교) **측정으로만** 풀린다
- 후보 ① **Δx(짧은 추가 마모)**: 5천 회 추가 시 68% 폭 23,500 → 13,000(약 45%↓, 저마모) — 비파괴성은 조금 잃는다
- 후보 ② **프로그램 시간**: v4.2 로 시험 — 폭 34k → 29k 로 좁아지나 칩마다 오르는 양이 달라 과신(합성 95% 96 → 84). 프로그램의 **칩 효과**를 따로 재면(오르는 칩이 더 쌓이면) 다시 쓸 수 있다
- 후보 ③ 섹터 간 산포 · 계단 유무 자체를 특징으로 — 느린 무리의 분포 폭 두 배가 이미 표지
- 한계 3 은 단열 상자 + 패키지 위 두 번째 TMP117(주소 ADD0) + 배치 사진을 시작 조건으로 — 이미 사양에 규칙으로 넣었다

노트: 「표본이 부족해서 모른다」 가 아니라 「무리당 3칩이면 된다는 것을 쟀다」 가 메시지. 두 번째 지표는 이미 한 번 시도해 왜 실패했는지까지 안다.

## 15. 이 시스템이 잘한 것 · 발전 가능성 (45초) · 발표 · 창의성

**메시지**: 20만 원대 벤치로, 비파괴 측정 1~5분에, 「몇 번 썼나」 를 믿을 수 있는 구간으로 — 그리고 그 길은 NAND 로 이어진다.

본문:
- **저비용 · 빠름**: Zybo Z7-20 + 소켓 보드 `[확인 필요: 총 부품비]`. 위상 스윕 1회 **59초**(N = 112, 5.78억 비트) · 역산 입력 prep 1회 약 **40초** · 계산 수 초 — 칩을 떼지 않고, 지우지 않은 섹터만 있으면 된다
- **표본은 부족하지 않다**: 학습 곡선이 빠른 무리 **3칩에서 포화** — 남는 오차(배율 약 1.4배)는 칩 수가 아니라 칩마다 늙는 속도가 다른 몫. 교정 곡선이 쌓일수록 **모델 식을 안 바꾸고** 정확해지는 구조(v4.3 은 6장 → 7장 곡선에서 판정 불변)
- **신품 31칩 · 마모 18칩 · 200k 이상 8칩 · 300k 1칩 · 블라인드 2칩 · 온도 5칩** — 4개월
- **발전 가능성**: ① SPI NAND(W25N) — 비트 에러 · ECC · Fail Map 이 등장하는 일반화 단계, 같은 벤치의 RTL 로 간다 ② 품번별 교정 곡선 라이브러리(무리당 3칩 규칙) ③ 「모른다」 고 말하는 판정 — 개체 지문(UID 꼴 · 신품 폭)으로 교정 밖 칩을 보류 ④ 온도 축 · 전압 축(레벨 시프터 보드)
