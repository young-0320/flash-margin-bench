| A2 | ★ NOR 연구가 부족하다는 근거는 | 편수를 센 통계는 아닙니다. Sakib · Guo 의 대상이 NAND 이고, Guo 는 NOR 를 향후 과제로 적었습니다. LIU 는 칩 수준 열화 연구가 적다고 썼습니다. NOR 연구가 없다는 뜻은 아닙니다. | [D10](#d10) |
| A3 | 선행 연구와 무엇이 다른가 | Sakib 은 데이터시트 기준 이진 판별, Guo 는 신품 등록이 필요한 점 추정입니다. 저희는 등록 없이 칩 안의 안 쓴 섹터로 구간을 답하고 처음 보는 칩으로 검증했습니다. | [D10](#d10) |
| A4 | ★ 세계 최초인가 | 그렇게 주장하지 않습니다. 사용량 추정은 Guo 2017 이 NAND 에서 먼저 했고, NOR 쪽 전방 인용 조사도 끝내지 않았습니다. | [D10](#d10) |

### 2.2 계산 순서 (교수님께 말로 설명)

**30초 답변**

> "먼저 안 닳은 섹터로 칩의 기준값을 잡아 무리를 나눕니다. 닳은 섹터 7개의 소거 시간을 기준값으로 나눠 배율을 만들고, 같은 무리 교정 곡선의 1k 지점마다 이 배율이 나올 가능성, 즉 우도를 계산합니다. 관측 7개가 완전히 독립은 아니어서 상관을 재서 정보량을 약 3.1개로 보정합니다. 칩마다 늙는 속도가 다르므로 가능한 속도 범위에 걸쳐 우도를 평균합니다. 사전 확률은 1-100k 에 평평하게 두어서, 이 값을 합이 1 이 되게 나누면 횟수별 확률이 되고, 거기서 사후 평균과 95% 구간을 냅니다."

**단계별 설명 (chip26 값)**

1. **기준값을 잡는다.** 안 쓴 섹터 32-127 의 소거 시간 중앙값 A 를 구한다. 그 칩의 신품값 대신이다. → 25.3ms
2. **무리를 나눈다.** A 가 40ms 미만이면 빠른 무리, 이상이면 느린 무리다. 이후에는 같은 무리 칩의 곡선만 쓴다. → 빠른 무리, 교정 6칩
3. **배율을 만든다.** 닳은 섹터 0-6 의 소거 시간을 각각 A 로 나눈다. 칩마다 다른 출발점이 지워진다. → 배율 7개, 중앙값 2.66배
4. **교정 곡선을 준비한다.** 교정 칩을 실제로 닳게 하며 잰 값으로, 1k 구간마다 배율이 어떻게 분포하는지 표를 만든다. 칩마다 늙는 속도가 다르므로 먼저 가로축을 맞춰 겹쳐 둔다.
5. **우도를 계산한다.** 곡선의 1k 지점마다 "이 지점의 칩이라면 지금 배율 7개가 나올 가능성"을 구한다. 배율 하나마다 칩 · 섹터별 분포에서 밀도를 읽어 평균하고, 7개 값은 로그로 평균한다.
6. **정보량을 보정한다.** 7개 섹터는 같은 칩이라 7개의 독립 증거가 아니다. 잰 상관(ρ)으로 유효 관측 수 n_eff 를 구해 우도에 반영한다. → 7개가 아니라 3.10개
7. **칩 속도를 반영한다.** 이 칩의 속도를 모르므로, 사용 횟수 후보 x 마다 곡선의 x/R 에서 x·R 까지 우도를 로그 눈금으로 고르게 평균한다. R 은 교정 칩의 속도 흩어짐에서 계산한다. → R 2.80
8. **확률로 바꾼다.** 사전 확률이 1-100k 에 평평하므로 7번 값의 합이 1 이 되게 나누면 1k 구간별 사후 확률이 된다.
9. **답을 낸다.** 사후 평균이 대표값이고, 확률이 큰 구간부터 모아 68% · 95% 구간을 만든다. 정격 대비 등급은 확률이 가장 큰 등급이다. → 60,001-61,000회, 95% 25,001-100,000회, 고마모

**수식 (참고)**

```text
입력    A = median(소거시간[섹터 32-127])
        y_i = 소거시간[섹터 i] / A                (i = 0-6, prep 여러 번이면 7·P 개)
무리    A < 40ms → 빠른 · 그 밖 → 느린

교정    구성원 m = (같은 무리 칩 j, 섹터 s) 의 공통 시계 지점 M 의 셀
        칩 속도 r̂_j 로 정렬: M 에는 칩 j 의 M / r̂_j 구간 셀을 넣는다
        셀 밀도 f_m(y): 분위수 21개(5% 간격) 사이를 조각마다 5% 균일 밀도로 둔다

곡선 우도
        log L(M) = n_eff · (1/N) · Σ_i log( mean_m f_m(y_i) )

유효 관측 수
        n_eff = 1 / ( ρ_chip + (1 - ρ_chip) · ( ρ_s/P + ρ_p/k + (1 - ρ_s - ρ_p)/(k·P) ) )
        k = 섹터 수(7) · P = prep 횟수

칩 속도 적분
        P(x | y) ∝ ∫[1/R, R] L(x·r) d(ln r) · 사전 p(x)
        사전 p(x) = x 는 1-100,000 의 1k 구간에 균등

속도 범위
        R = exp( 1.96 · σ_r · sqrt(1 + 1/M) )     (σ_r = 교정 칩 ln r̂_j 의 표준편차 · M = 교정 칩 수)

출력    대표값 = 사후 평균이 든 1k 구간
        68% · 95% 구간 = 확률 큰 1k 구간부터 모은 HPD
        등급 = 정격 대비 1% · 20% · 60% · 100% 까지 신품 · 저마모 · 중마모 · 고마모 중 확률 최대
```
