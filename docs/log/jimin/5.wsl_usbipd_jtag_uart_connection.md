# WSL USB 포트 연결 및 확인

Zybo 보드의 USB(JTAG·UART)를 WSL Ubuntu에서 인식시키는 명령만 정리한다.

> 이 PC에서는 Ubuntu와 Vivado/Vitis 환경이 Windows의 `master` 사용자에 등록되어 있다.
> 따라서 아래 `usbipd attach`는 `PS C:\Users\master>` PowerShell에서 실행한다.
> `418cj` 사용자에서 실행하면 `There are no WSL distributions installed`가 나올 수 있다.

## 1. 보드 연결

1. Zybo 보드에 USB 케이블을 연결한다.
2. 보드 전원을 켠다.
3. Windows의 `master` 사용자로 PowerShell을 연다.

PowerShell 프롬프트가 다음과 같은지 확인한다.

```text
PS C:\Users\master>
```

필요하면 기존 Ubuntu가 등록되어 있는지도 확인한다.

```powershell
wsl --list --verbose
```

`usbipd`는 Ubuntu 명령이 아니라 Windows 명령이다. Ubuntu에서 `usbipd list`를 실행하거나
`apt install`로 설치하지 않는다.

## 2. Windows에서 BUSID 확인

Windows PowerShell에서 실행한다.

```powershell
usbipd list
```

목록에서 VID:PID가 `0403:6010`이고 장치 이름이 `USB Serial Converter A, USB Serial
Converter B`인 행의 `BUSID`를 찾는다. 2026-09-16 실측에서는 다음과 같이 `1-7`이었다.

```text
1-7    0403:6010  USB Serial Converter A, USB Serial Converter B  Shared
```

USB를 다시 연결하면 BUSID가 바뀔 수 있으므로 `1-7`을 외우지 않고 매번 현재 목록을 확인한다.

## 3. 최초 한 번만 공유

장치 상태가 아직 `Shared`가 아니라면 **관리자 PowerShell**에서 실행한다. 아래 `<BUSID>`에는
2단계에서 확인한 값을 넣는다.

```powershell
usbipd bind --busid <BUSID>
```

다음 메시지는 이미 공유돼 있다는 뜻이므로 정상이다.

```text
Device with busid '<BUSID>' was already shared.
```

이미 `Shared`이면 `bind`를 다시 실행할 필요가 없다. `bind`에만 관리자 권한이 필요하며,
다음 `attach`는 일반 PowerShell에서 실행해도 된다.

## 4. WSL에 연결

`PS C:\Users\master>` PowerShell에 입력한다.

```powershell
usbipd attach --wsl --busid <BUSID>
```

2026-09-16 실측 BUSID를 그대로 쓰면 다음과 같다.

```powershell
usbipd attach --wsl --busid 1-7
```

`There are no WSL distributions installed`가 나오면 새 Ubuntu를 설치하지 않는다. 현재
PowerShell이 `C:\Users\418cj`에서 열린 것이 아닌지 확인하고, 기존 개발 환경이 등록된
Windows `master` 사용자로 돌아가서 실행한다.

연결 상태 확인:

```powershell
usbipd list
```

해당 장치의 상태가 `Attached`이면 Windows 쪽 연결은 완료다.

## 5. Ubuntu에서 포트 확인

Ubuntu 터미널에서 실행한다.

```bash
lsusb | grep 0403:6010
ls -l /dev/ttyUSB*
```

2026-09-16 정상 확인 결과:

```text
Bus 001 Device 002: ID 0403:6010 Future Technology Devices International, Ltd FT2232C/D/H Dual UART/FIFO IC
crw-rw-rw- 1 root dialout 188, 0 Sep 16 15:17 /dev/ttyUSB0
crw-rw-rw- 1 root dialout 188, 1 Sep 16 15:17 /dev/ttyUSB1
```

다음 두 가지가 모두 확인되면 연결 성공이다.

- `lsusb`에 `0403:6010`이 표시됨
- `/dev/ttyUSB0`, `/dev/ttyUSB1`이 모두 생성됨

이 프로젝트의 UART 포트는 일반적으로 `/dev/ttyUSB1`을 사용한다.
