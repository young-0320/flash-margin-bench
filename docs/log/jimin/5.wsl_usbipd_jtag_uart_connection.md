# WSL USB 포트 연결 및 확인

Zybo 보드의 USB(JTAG·UART)를 WSL Ubuntu에서 인식시키는 명령만 정리한다.

## 1. 보드 연결

1. Zybo 보드에 USB 케이블을 연결한다.
2. 보드 전원을 켠다.
3. Ubuntu 터미널을 하나 열어 둔다.

## 2. Windows에서 BUSID 확인

Windows PowerShell에서 실행한다.

```powershell
usbipd list
```

목록에서 FTDI/FT2232 장치의 `BUSID`를 찾는다. 예전에는 `1-1`이었지만 다시 연결하면
번호가 바뀔 수 있으므로 현재 목록을 확인한다.

## 3. 최초 한 번만 공유

장치 상태가 아직 `Shared`가 아니라면 **관리자 PowerShell**에서 실행한다.

```powershell
usbipd bind --busid 1-1
```

다음 메시지는 이미 공유돼 있다는 뜻이므로 정상이다.

```text
Device with busid '1-1' was already shared.
```

## 4. WSL에 연결

Ubuntu 터미널을 열어 둔 상태에서 Windows PowerShell에 입력한다.

```powershell
usbipd attach --wsl --busid 1-1
```

`1-1`은 `usbipd list`에서 확인한 실제 BUSID로 바꾼다.

연결 상태 확인:

```powershell
usbipd list
```

해당 장치의 상태가 `Attached`이면 Windows 쪽 연결은 완료다.

## 5. Ubuntu에서 포트 확인

Ubuntu 터미널에서 실행한다.

```bash
lsusb | grep 0403:6010
ls -l /dev/ttyUSB*
```

정상 예시:

```text
Bus 001 Device 003: ID 0403:6010 Future Technology Devices International FT2232
crw-rw-rw- 1 root dialout ... /dev/ttyUSB0
crw-rw-rw- 1 root dialout ... /dev/ttyUSB1
```

다음 두 가지가 모두 확인되면 연결 성공이다.

- `lsusb`에 `0403:6010`이 표시됨
- `/dev/ttyUSB0`, `/dev/ttyUSB1`이 모두 생성됨

이 프로젝트의 UART 포트는 일반적으로 `/dev/ttyUSB1`을 사용한다.
