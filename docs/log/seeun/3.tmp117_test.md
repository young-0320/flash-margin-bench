# 3. TMP117 단독 연결 및 온도 읽기 시험

- **시험일**: 2026-09-21
- **시험 단계**: `docs/log/seeun/2.temperature_bench_design.md`의 단계 B
- **목적**: 히터와 MOSFET을 연결하기 전에 Arduino가 TMP117을 I²C로 인식하고 온도값을 읽는지 확인
- **스케치**: `arduino/tmp117_test/tmp117_test.ino`

## 1. 시험 범위

이번 시험에서는 히터 전원, 필름 히터, MOSFET 모듈 및 퓨즈를 연결하지 않았다. Arduino Uno와
TMP117 모듈만 연결해 다음 항목을 확인했다.

1. Arduino 스케치 컴파일 및 업로드
2. I²C 버스에서 TMP117 주소 검색
3. TMP117 장치 ID 확인
4. 온도 레지스터 읽기 및 섭씨 변환
5. 센서 오류가 발생했을 때 오류 메시지 출력

## 2. 사용 장비

| 항목 | 용도 |
| --- | --- |
| Arduino Uno | TMP117 I²C 통신 및 시리얼 출력 |
| TMP11X V1.0 보드에 실장된 TMP117 | 온도 측정 |
| 브레드보드와 점퍼선 | 전원·I²C 배선 |
| 4.7kΩ 저항 2개 | SDA와 SCL 풀업 |
| USB 데이터 케이블 | Arduino 전원·스케치 업로드·시리얼 통신 |
| Arduino IDE 2.3.10 | 컴파일, 업로드, 시리얼 모니터 |

## 3. 배선

Arduino의 USB 전원을 뺀 상태에서 다음과 같이 연결한다.

| TMP117 모듈 | Arduino Uno | 설명 |
| --- | --- | --- |
| VCC | 3.3V | 센서 전원 |
| GND | GND | 공통 기준 전압 |
| SDA | A4/SDA | I²C 데이터 |
| SCL | A5/SCL | I²C 클럭 |

풀업저항은 신호선과 직렬로 넣지 않는다. SDA와 SCL에 각각 별도의 저항을 사용한다.

```text
Arduino 3.3V ─────────────── TMP117 VCC
Arduino GND  ─────────────── TMP117 GND

Arduino A4/SDA ───────────── TMP117 SDA
       │
       └──── 4.7kΩ ───────── Arduino 3.3V

Arduino A5/SCL ───────────── TMP117 SCL
       │
       └──── 4.7kΩ ───────── Arduino 3.3V
```

SDA와 SCL은 서로 연결하지 않는다. 브레드보드에서는 3.3V 전원 레일에 TMP117 VCC와 두
풀업저항의 한쪽 다리를 연결하고, 각 저항의 반대쪽 다리는 SDA 노드와 SCL 노드에 하나씩
연결한다.

## 4. 실제 온도 측정 위치

TMP117의 측정부는 노란색 4핀 커넥터 반대편의 가늘고 둥근 프로브 끝에 실장된 작은 검은색
정사각형 IC다. TMP117은 이 IC 내부 반도체의 온도를 측정한다. 손가락 가열 시험에서는 이
검은색 IC 위를 10~20초 동안 가볍게 접촉하고 온도 상승을 확인한다.

정전기 방지 봉투는 전기적으로 도전성을 가질 수 있으므로, 전원을 인가한 센서 보드를 봉투
위에 두지 않고 비전도성 작업면 또는 브레드보드 위에서 시험한다.

## 5. 스케치 동작

스케치는 Arduino 기본 `Wire` 라이브러리만 사용하며 다음 순서로 실행된다.

1. I²C 전체 주소를 스캔한다.
2. TMP117에서 가능한 `0x48`~`0x4B` 주소를 검사한다.
3. 장치 ID 레지스터 `0x0F`를 읽어 하위 12비트가 `0x117`인지 확인한다.
4. 온도 레지스터 `0x00`에서 16비트 값을 읽는다.
5. 2의 보수 부호값으로 해석한 뒤 `128`로 나눠 섭씨 온도로 출력한다.
6. 센서가 응답하지 않으면 오류를 출력하고 온도값을 사용하지 않는다.

I²C 장치 주소와 내부 레지스터 주소는 서로 다른 값이다.

```text
0x48 = I²C 버스에서 TMP117 장치를 선택하는 주소
0x00 = 선택한 TMP117 내부에서 최신 온도값을 보관하는 레지스터 주소
0x0F = TMP117 장치 ID를 보관하는 레지스터 주소
```

## 6. 업로드 절차와 COM 포트 문제

1. Arduino IDE에서 보드를 `Arduino Uno`로 선택한다.
2. 실제 연결된 포트를 선택한다.
3. 스케치를 업로드한다.
4. 시리얼 모니터를 열고 전송 속도를 `115200 baud`로 설정한다.

첫 업로드에서는 과거에 선택된 `COM8`을 Windows가 찾지 못해 다음 오류가 발생했다.

```text
Error: cannot open port \\.\COM8
Failed uploading: uploading error: exit status 1
```

Arduino를 다시 연결한 뒤 IDE에 표시된 실제 포트 `COM10`을 선택해 업로드했다. 컴파일 결과는
프로그램 저장 공간 6,788바이트(21%), 전역 변수 421바이트(20%)였으며 업로드에 성공했다.

## 7. 확인 결과

시리얼 모니터에서 다음 유효 출력이 확인되었다.

```text
address=0x48  register=0x00  raw=0x0D86  temperature=27.047 C
```

이를 해석하면 다음과 같다.

```text
I²C 주소: 0x48
온도 레지스터: 0x00
원시값: 0x0D86 = 3462
온도: 3462 / 128 = 27.046875°C ≈ 27.047°C
```

따라서 Arduino와 TMP117 사이의 I²C 통신, 온도 레지스터 읽기 및 섭씨 변환까지 정상 동작하는
것을 확인했다.

시리얼 모니터에는 일부 깨진 문자가 섞여 출력되었다. 코드가 출력하는 측정 문자열은 ASCII이고
정상 온도 줄이 반복 확인되었으므로, 깨진 문자는 온도값이 아니라 시리얼 표시 오류다. 시리얼
모니터를 `115200 baud`로 맞춘 뒤 출력을 지우고 Arduino를 한 번 리셋해 다시 확인한다. 시작
안내문이 반복된다면 Arduino가 재부팅되는 것이므로 USB 케이블, USB 포트, 3.3V/GND 단락 및
느슨한 배선을 점검한다.

## 8. 단계 B 진행 상태

| 확인 항목 | 상태 | 근거 |
| --- | --- | --- |
| Arduino 스케치 컴파일·업로드 | 완료 | Arduino Uno, COM10에서 업로드 성공 |
| TMP117 I²C 주소 확인 | 완료 | `0x48` 응답 확인 |
| 온도 레지스터 `0x00` 읽기 | 완료 | `0x0D86`, `27.047°C` 출력 확인 |
| 손가락 가열에 따른 온도 상승·하강 | 확인 필요 | 검은색 센서 IC를 10~20초 접촉해 변화 기록 필요 |
| 센서 분리 시 오류 검출 | 확인 필요 | SDA 분리 후 오류 출력 및 재연결 복구 확인 필요 |

다음 시험에서는 실온에서 30초 이상 값을 기록한 뒤 센서 IC를 손가락으로 10~20초 접촉하고,
온도가 상승한 후 다시 실온 방향으로 내려오는지 확인한다. 이어서 히터가 없는 상태에서 SDA를
분리해 `[ERROR] TMP117 not found or I2C read failed.`가 출력되는지 확인한다.
