### 2.1 얻은 값 셋

**① 출고 blank 최초 관측 (chip03).** 8MB 전역에 0으로 굳은 비트 0개. 로그 30 §2가 사전에
적어 둔 예상("10개 전부 bits=0일 가능성이 높다 — 발견이 아니라 보험")의 첫 실측 확인이다.

**② 소거 시간 개체차 1.88배.** 마모 탓이 아니다 — 소거 시간은 마모될수록 늘어나는데 P/E 5회인
chip02가 1회인 chip03보다 빠르다. 방향이 반대다. 섹터 간 산포는 둘 다 ±17%로 같고 다른 것은
**중앙값 자체**다. 방법론에 닿는 결론은 집계표 §1에 적었다 — 요지는 **절대 소거 시간을 칩 간
비교 지표로 쓸 수 없고, 교정 곡선은 각 칩 자신의 t=0 대비 상대 변화로 세워야 한다**는 것이다.
전수 신품 측정이 블라인드 추정의 전제임이 여기서 실증됐다.

**③ 세션 간 재현성 σ = 4.65ps (chip02 3회).** 리포에 없던 값이다. chip01의 ±0.61ps는 한 세션
안 연속 5회라 재프로그래밍·MMCM 재락 성분이 빠져 있었다. **재장착 성분은 아직 없다** — S-2 §8
앵커 측정에서 확보한다.

### 2.2 chip01 ↔ chip02 의 106ps

chip01 39,737.3(2024.2·N=100·115200) vs chip02 39,630.2(2025.2·N=112·921600). 세션 간 σ 기준
22σ라 노이즈가 아니지만, **개체 차이와 빌드 세대 차이가 분리되지 않았다.** chip01 회수 시
같은 조건으로 1회 재측정해 가른다(§5 미결 1). 그때까지 두 값을 같은 축에 놓지 않는다.

## 3. 결정 4건

| ID | 결정 | 근거 |
| -- | ---- | ---- |
| E1 | **S-1 §12 시간 예산 개정** — 스윕 5.6분 → 59초, 체크포인트 본실험 84분 → 15분 | "(실측 확인 대상)"으로 열어 둔 항목이 실측됐다. §11 적응적 조밀화에서 점을 더 촘촘히 박을 여유가 생긴다 — 종전엔 점당 84분이 1차 비용 동인이었다(로그 17 §7) |
| E2 | **드리프트 앵커 chip01 → chip02** | chip01이 팀원에게 가 있어 세션에 끼울 수 없고, 앵커가 없으면 S-2 §6.3의 분모가 안 생겨 전수 측정 전체가 해석 불능이 된다. "한 칩을 반복해 노이즈 플로어를 만든다"가 요구사항이고 개체 지정은 수단이다. 로그 29 D5 조건 ②도 함께 해소 |
| E3 | **집계표를 `docs/results/data/`에 지금 개설** (완료 전엔 진행 상태 표기) | 9칩을 다 돌고 만들면 세션 로그 9개를 거꾸로 파싱해야 한다. 무엇보다 S-2 §6.2 이상치 판정은 **칩이 소켓에 꽂혀 있는 동안** 해야 재장착 재측정이 가능하다 |
| E4 | **측정 원본을 `build_*/`에 두지 않는다** | `build_2024.2/data/`에 게재물 1번의 `_reads` 원본(2.45MB)이 있었다. `build_*/`는 "지워도 되는 폴더"라 사고 대기 상태였다. `data/`로 복사하고 `data/README.md`에 보관 현황을 명문화 |

**E1·E2는 사양 개정**이므로 해당 문서에 개정 일자와 근거를 달았다(S-1 머리말·§12, S-2 머리말·§8).
