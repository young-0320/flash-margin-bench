## 근거

### 1. 교수님 피드백 (11/2 미팅)

| # | 요구 |
| - | ---- |
| 1 | 욕조 곡선 x축 스케일 조정 — 가운데는 점이 안 찍히니 생략하고, 0 근처와 40,000ps 근처(양쪽 벽)를 확대 |

참고 자료로 교수님의 2013년 KAIST CoCoA 랩 세미나 슬라이드를 받았다. Dong 외(TVLSI 2012)의 NAND 오류 모델링을 소개하는 내용이다 — 소거 상태는 가우시안, 프로그램 상태는 ISPP 균등 분포, RTN, 셀 간 간섭, 보존. 전반적인 방향은 **욕조 곡선 쪽을 더 밀어 보라**는 것이었다.

### 2. 그 자리에서 본 것 — 비대칭의 단서

리포의 chip01 7/8 스윕 한 회분으로 시험 그림 두 장을 그렸다. 하나는 양쪽 벽 확대, 다른 하나는 좌우 벽을 같은 방향으로 겹친 비교다. 그림은 리포에 남기지 않았다.

욕조 천장의 오류 수가 11스텝 내내 정확히 50,416개였고, 이 값이 PRBS 의 한쪽 방향 전이(0→1 또는 1→0) 개수와 같았다. 교수님 말씀대로 0과 1의 차이가 맞지만, 셀 문턱 전압 분포보다는 출력 에지 방향의 타이밍 차이로 읽었다. 왼쪽 벽은 한 종류 에지, 오른쪽 벽은 다른 종류 에지의 시각 분포라는 해석이다. 셀 분포 해석을 버린 것은 아니다 — §3 의 판별 실험이 그 갈림이다.

### 3. 제안한 후속 작업 (구현 안 함)

- **벽 집중 측정**: 가운데를 건너뛰고 읽기를 양쪽 벽에 몰아 더 깊은 BER 까지 본다. 펌웨어만 고치면 된다
- **기대값(0/1)별 오류 계수기**(RTL): 각 벽이 어느 에지인지 확정하고 「0과 1의 pdf」 를 직접 뽑는다
- **계약 수정안 #1(BASE_SECTOR) 구현**: 이미 닳은 칩에서 닳은 영역과 안 닳은 영역을 같은 세션에 비교한다. 다시 마모할 필요가 없다
- **셀 쪽인지 출력단 쪽인지 판별**: 체크포인트별로 벽 모양(비대칭)이 마모에 따라 변하는지 본다. 변하면 셀 쪽, 그대로면 출력단 쪽이다

### 4. 못 한 것

피드백 4 · 5(칩별 평균과 산포, 체크포인트별 평균)는 스윕 원본이 PC 의 `data/` 에만 있어 그 세션에서 하지 못했다. 비대칭 분석은 chip01 한 회분으로만 봤고, 반복 5회분과 다른 칩으로 확인해야 한다.
