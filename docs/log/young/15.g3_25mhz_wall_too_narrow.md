## 근거

### 1. 함정 — 치환 생성은 재빌드해야 반영된다

D3 재실행 전에 걸린 것이 있다. G3용 3개 클럭 ELF 가 `line_dead` 자가진단 수정(커밋
`eaa0fa1`, 22:28)보다 12시간 전(10:10)에 빌드된 채 남아 있었다.

[로그 12](12.realchip_prep_batch.md) [D12-1] 의 "원본 치환 생성이라 자동 반영"은 **재빌드
시에만** 반영된다는 뜻이다. 실제로 재빌드 없이 D3 을 먼저 돌려 `line_dead_unknown` 으로
594스텝에서 중단되는 `_invalid` 를 한 번 만들었다. 3개 전부 재빌드하고 재실행해서
`valid=1 reason=complete` — 첫 완주 실칩 곡선이다.

### 2. 자가 굵어서 못 재는 것이지 곡선이 나쁜 게 아니다

25MHz: width@θ=1e-2 = 39,737ps (UI 40,000ps). 체크 2(floor 상한 3.25e-9)·4(F=0.48)·5 PASS,
**체크1 SKIP** — 실측 오류가 스텝 587~605(19스텝, ~302ps)에만 몰려 있어 편당 4점 fit 최소
조건(BER∈[1e-4,5e-2])을 못 채운다(왼쪽 1점, 오른쪽 2~3점).

45MHz 로 올려도 같았다: width@1e-2 = 21,897.6ps / UI 22,222ps, 체크 2(5.9e-9)·4·5 PASS,
체크1 또 SKIP. 벽 폭이 25MHz ~302ps(19스텝) ↔ 45MHz ~381ps(24스텝)로 UI 와 무관하게
유지되고, 천이가 한 스텝(15.87ps) 만에 BER 1e-4 → >5e-2 로 점프해 probit 대역 표본이 두
클럭 모두 3점이다.

Δφ=15.873ps 는 VCO 고정이다(계약 결정 16). **그래서 어느 클럭에서도 체크1 은 구조적으로
SKIP 이다** — 사다리를 올리면 통계가 잡힌다던 처방은 오진이었다. 대신 UI 가 반토막 나도 벽
폭이 유지된다는 교차 검증을 얻었다: 벽은 프로토콜 아티팩트가 아니라 채널 물리다.

함의는 하나 더 있다. 실칩 채널이 루프백(σⱼ≈29ps)보다 훨씬 가파르다는 것은
[로그 13](13.first_loopback_bathtub_and_linedead_fix.md) [U13-1] 의 가설 — 결정론적 평탄부가
가우시안 모델을 위반한다 — 을 강화한다.

### 3. 벽 모서리 — 가우시안이 안 맞는다는 증거 둘

벽 모서리 인접 2점으로 σⱼ 를 추정하면 25MHz 좌 6.3 / 우 10.8ps, 45MHz 좌 9.0 / 우 10.8ps
다. 두 독립 스윕·네 모서리에서 6~11ps 로 일관하니 값·상한으로는 보고 가능한 등급이다.
루프백(29ps)의 약 1/3 이다.

가우시안 부적합 증거는 둘이다.

1. 45MHz 좌벽 3점(9.8e-6→6.1e-3→4.9e-2)의 구간 기울기가 σ 9.2→18.4ps 로 2배 꺾인다.
   직선이 아니고, 자유도 1에서 즉시 검출된다
2. 벽 평탄부가 BER 0.5 가 아니라 **0.246 에서 포화** 한다 — 비트 절반만 취약하다는
   결정론적 패턴 의존성을 시사한다

루프백 R²=0.974 FAIL([로그 13](13.first_loopback_bathtub_and_linedead_fix.md))과 같은
방향이다.

실무 함의도 따라온다: θ=1e-2/1e-3/1e-4 폭 차이가 25MHz 에서 총 27ps (39,737 / 39,724 /
39,710)라 θ 민감도가 사실상 소멸한다. 이 부류는 가우시안 외삽 보정이 필요 없는, 실측 폭을
직독하는 결정론 지배 채널로 보는 것이 자연스럽다.

### 4. 3점째가 "벽 폭은 UI 와 무관"을 깼다

75MHz: width@1e-2 = 12,205.3ps (UI 13,333ps 의 91.5%). 체크 2(1.06e-8)·4(F=0.36)·5 PASS,
체크1 SKIP 동일.

| 클럭 | UI | width@1e-2 | 벽 폭 | 천장 BER | 2점 σⱼ (L/R) |
| ---- | -- | ---------- | ----- | -------- | ------------- |
| 25MHz | 40,000ps | 39,737ps (99.3%) | ~302ps (19스텝) | 0.2462 | 6.3 / 10.8ps |
| 45MHz | 22,222ps | 21,898ps (98.5%) | ~381ps (24스텝) | 0.2462 | 9.0 / 10.8ps |
| 75MHz | 13,333ps | 12,205ps (91.5%) | **~1,175ps (74스텝)** | 0.2462 | 13.0 / 16.0ps |

**정정**: "벽 폭이 UI 와 무관하게 일정"은 2점 시점의 잠정 결론이었고 3점째에서 깨졌다 —
302→381→1,175ps 로 클럭에 따라 증가한다. 데이터 의존 지연 퍼짐(ISI 류)이 고클럭에서 UI
대비 커지는 대역폭 제한형 거동으로 읽힌다. 다만 "벽 = 채널 물리"라는 결론은 오히려
강화된다 — 프로토콜 아티팩트라면 스텝 수가 클럭에 따라 이렇게 체계적으로 늘 수 없다.

**천장 BER 0.2462 가 세 클럭에서 완전히 동일한 것** 이 결정론적 패턴 의존성의 가장 강한
단일 증거다. 클럭을 3배 올려도 취약 비트 집합의 비율이 변하지 않는다. θ 둔감성도 유지된다
(75MHz 에서 θ 1e-2→1e-4 폭 차 39ps, 0.3%).

### 5. 무엇을 주장하고 무엇을 주장하지 않나

중간보고서 한계 절 초안이다 (체크1 거취와 무관하게 사용 가능).

> 측정된 벽 천이는 위상 해상도(Δφ=15.87ps, MMCM VCO 고정) 대비 지나치게 가팔라
> (2점 추정 σⱼ≈6~11ps), 가우시안 꼬리 외삽의 자격 검증(probit 선형성, 편당 4점)이
> 성립하지 않았다. 따라서 BER 10⁻¹² 기준 외삽 폭은 제시하지 않는다. 다만 판정 기준 θ를
> 10⁻²에서 10⁻⁴로 조여도 실측 폭 변화가 27ps(0.07%)에 그쳐, 본 채널은 결정론 성분이
> 지배하는 저지터 채널로 판단되며 실측 폭의 대표성은 θ 선택에 둔감하다. 추가 판독(포화
> 천장 0.246, 구간 기울기 비선형)은 단일 가우시안 모델의 부적합을 시사하므로, 후속
> 연구에서 2성분 지터 모델(dual-Dirac)의 적용을 검토한다.

"관측 밖 절벽 보증" 공격에 대비한 방어 문장을 초안 문단 뒤에 붙인다.

> 관측 범위(θ ≥ 10⁻⁴) 밖에서 가우시안 잔여 지터에 의한 추가 협착이 존재하더라도, 2점
> 추정 σⱼ ≤ 11ps를 대입하면 BER 10⁻¹² 기준 추가 협착은 양벽 합계 약 75ps(실측 폭의
> 0.2%) 이내로 상한된다(10⁻⁴↔10⁻¹² = 편당 약 3.4σ). 이는 보증이 아닌 모델 의존 상한
> 추정이며, 꼬리가 가우시안보다 무거운 경우(RTN 등)는 포괄하지 않는다.

논리는 3층이다 — ① 실측 폭은 무보정 직독(주장) ② 10⁻¹² 는 주장하지 않음(한계 명시)
③ 그 미지가 결론을 뒤집을 수 없음을 상한으로 제시(방어). dual-Dirac 이 "검토" 수준에
머무는 것은 자 해상도 한계가 그대로이기 때문이다.

### 6. 승격처 표기는 실물을 따라간다

계약 §6 이 `docs/reports` 를 가리키고 있었는데 실제 승격처는 `docs/results` 다. 문서가
없는 곳을 가리키면 그 조항은 집행되지 않는다.

### 7. 반복 5회 — 측정이 노이즈가 아니라 신호다

25MHz 를 재장착 없이 연속 5회 돌려 5/5 valid 를 받았다. `repeatability_aggregate.py` 로
집계한 결과가 width@1e-2 = 39,737.3 ± 0.61ps (상대 0.0015%), @1e-3 = 39,724.2 ± 0.79ps,
@1e-4 = 39,710.6 ± 0.95ps 다.

반복 표준편차가 1ps 미만이라는 것이 G4("측정이 노이즈가 아니라 신호")의 정량 증거이고,
G5 게이트 ②(노이즈 플로어 ≪ 노화 이동량)의 선행 지표이기도 하다. 다만 이 반복은
재장착·보드·일자를 포함하지 않으므로 %GRR 로 부르지 않는다.
