# 9. G2 JEDEC 브링업 준비 — 하드웨어 절반 완성

- **작성일**: 2026-07-07
- **발단**: 게재 목록 2번(보드-모듈 통신 증거, G2 승격 판정 지점)은 장세은 담당인데,
  Vivado 쪽까지 세은이 처음부터 만들면 마감 전에 안 끝난다
- **목적**: 세은 몫을 얼마까지 줄여 놓을 수 있나?
- **관련**: `fpga/scripts/build_g2_jedec.tcl` · `fpga/constraints/g2_jedec_pins.xdc` ·
  `ps/scripts/program_g2.tcl` · [로그 8](8.vivado_integration_and_sweep_sw.md)

- [D9-1] Vivado 절반(BD·비트스트림·핀 배정·프로그래밍)을 Young 이 미리 만들고, 세은 몫은
  **배선 + 베어메탈 C + 캡처** 로 줄인다 — §0 · §3~§5
- [D9-2] PS 하드 SPI0 을 EMIO 로 꺼내 JB 에 직결한다. PL 로직 0 — §0 ·

- [D9-3] JB 핀 배정 = Pmod Interface Spec Type 2 표준으로 확정 — 게재 4번(실칩 곡선)의

- [D9-4] SOP8 직결 시 `/WP`(3번)·`/HOLD`(7번)를 3V3 에 묶는 것을 배선 요건으로 못박는다 — §2
- [D9-5] 게재 2번 앱 스펙 — XSpiPs 폴링 `0x9F`, 1초 주기 반복, 사람이 읽는 판정 문구까지

- [D9-6] 프리스케일러 64(SCLK ≈ 2.6MHz) — 브링업 보수값. §4 에서 끝나는 값이다 — §3

## 근거

### 0. 디버그할 표면을 C 하나로 좁힌다

PL 로직이 하나도 없으면 세은이 들여다볼 곳이 베어메탈 C 하나뿐이다. SS_I=1 고정(0이면
mode fault 로 마스터가 강등된다)·SCLK_I/MOSI_I=0 고정으로 EMIO 입력단을 묶었다.

`program_g2.tcl` 은 ps7_init 을 XSA(zip)에서 직접 추출한다 — 세은 앱 워크스페이스가 어떤
구조든 무관하게 한 줄로 프로그래밍된다.

### 1. 핀 배정 — Pmod SPI 표준 (배선 기준표)

| JB 핀 | 신호 | FPGA 핀 | W25Q64 (SOP8) |
| ----- | ---- | ------- | ------------- |
| JB1   | CS   | V8      | /CS (1번 핀)  |
| JB2   | MOSI | W8      | DI (5번 핀)   |
| JB3   | MISO | U7      | DO (2번 핀)   |
| JB4   | SCLK | V7      | CLK (6번 핀)  |
| JB5   | GND  | —      | GND (4번 핀)  |
| JB6   | 3V3  | —      | VCC (8번 핀)  |

표준 배열을 쓰는 이유는 이 표가 여기서 끝나지 않아서다 — 게재 4번의 실칩 XDC 가 같은 표를
승계한다.

### 2. /HOLD 플로팅은 "가끔만 되는" 증상을 남긴다

`/HOLD` 가 플로팅으로 낮게 읽히면 칩이 통신을 일시정지한다. 고장이 결정론적이면 차라리
빨리 잡히는데 이건 간헐이라 최악 유형이다. 완제품 모듈이면 보통 내장 풀업이라 확인만 하면
된다.

### 3. 베어메탈 C 스펙 (`ps/src/`, 세은 작성)

- 초기화: `XSpiPs_LookupConfig(XPAR_XSPIPS_0_BASEADDR)` — **2024.2 SDT 플로우는 DEVICE_ID 가
  아니라 BASEADDR 을 받는다.** 구버전 예제를 복붙하면 여기서 컴파일 에러가 난다
- 옵션: `XSPIPS_MASTER_OPTION | XSPIPS_FORCE_SSELECT_OPTION`, `XSpiPs_SetSlaveSelect(&spi, 0)`,
  프리스케일러 64 (SPI ref 166.67MHz → SCLK ≈ 2.6MHz). JEDEC 은 저속으로 충분하고, 이 값은
  게재 4번에서 SPI 마스터 RTL 로 대체되므로 여기서 수명이 끝난다
- 트랜잭션: tx `{0x9F,0,0,0}` 4바이트 `XSpiPs_PolledTransfer` → rx[1..3] = `EF 40 17` (W25Q64)
- 출력: 1초 주기 `xil_printf` 반복 (UART 115200). 무칩·오배선이면 `FF FF FF` 또는 `00 00 00`

판정 문구까지 출력하게 한 것은 게재물 때문이다 — 사람이 읽고 판정할 수 있는 화면이어야
캡처 1장이 그대로 증거가 된다.

### 4. 빌드 — 클래식 xsct 배치가 죽는 설치본이다

`ps/scripts/build_g0_sweep.py` 를 복사해 XSA 경로만 G2 것으로 바꿔 `vitis -s` 로 빌드한다.
클래식 xsct 프로젝트 명령은 이 설치본에서 죽는다([로그 8](8.vivado_integration_and_sweep_sw.md)).
본인 노트북 Vitis 를 쓰려면 2024.2 이상이어야 XSA 가 열린다.

### 5. 실행·캡처가 곧 승격 판정이다

`program_g2.tcl` 로 프로그래밍하고 UART 에 `EF 40 17` 이 찍힌 화면을 캡처하면, 그 한 장이
게재물이면서 동시에 게재 4번(실칩 곡선)으로 넘어가는 승격 판정이다. 두 일을 따로 하지
않는다.
