## 근거

### 1. 게재 4항목과 cocotb 강등

몬테카를로 근거 그림 2장은 이미 확보돼 있고, 나머지 셋은 하드웨어 사슬에 걸려 있다. cocotb
는 마감 시점에 회귀 PASS 가 존재하면 캡처 1장으로 줍는 정도로 내렸다. **G1 작업 자체**는
유지한다 — 팀원 A 트랙이고, 시뮬레이션 선검증이 G2 브링업 리스크를 줄인다.

### 2. 총력전 중에도 계약만은 기록한다

전원을 크리티컬 패스(G0→G2→G3)에 투입하면서 폴더 소유와 PR 규칙을 멈췄다. 다만 인터페이스
합의 4건(core↔flash 핸드셰이크, AXI-Lite 레지스터 맵, 에러 카운터 폭·집계, UART/CSV 스키마)은
구두로 정하는 즉시 `docs/interface/` 에 한 줄 기록한다. 규칙을 멈추는 것과 합의를 흘리는 것은
다르다.

### 3. 마모는 게재하지 않고 "안 한 이유"를 쓴다

마모 측정은 G5 게이트 위반(자기모순)이고, 시료가 비가역으로 소실되며, 크리티컬 패스를
잠식한다. 셋 중 하나만으로도 제외 사유가 되므로 대신 방법론 서술("마모를 안 한 이유")로
대체한다.

### 4. 개명과 uv

`mc_reads_per_phase.py` 는 이름이 불투명한 약어(mc)이고 범위(θ 스윕까지 포함)보다 좁다.
출력 파일명·`bathtub_analysis.py` 의 import·docstring 상호 참조·개념 문서·이전 로그의 경로
언급을 전부 동기화했다.
