# 해외논문조사

해외 선행연구들은 대부분 NAND Flash의 Vth 분포, read reference voltage, failbit, P/E cycle, retention, 온도 조건을 이용해 수명과 신뢰성을 평가한다. 우리는 제조사급 장비 없이 상용 SPI Flash에서 내부 Vth를 직접 볼 수 없으므로, FPGA의 ps 단위 위상 스윕으로 외부에서 관측 가능한 타이밍 마진 폭을 측정한다. 이게 차별점이다. 

즉, 대부분의 선행연구는 raw NAND chip, SSD 내부 정보, read reference voltage 제어, Vth 분포 측정 장비 등 **제조사급 또는 연구실급 접근권한**을 전제로 한다는 점이다.

💡우리 프로젝트가 필요한 이유는 여기서 나온다.

SPI NOR Flash는 임베디드 시스템, 산업 제어기, 차량용 ECU 등에서 부트코드와 펌웨어를 저장하는 핵심 메모리로 사용된다. 이 메모리에 저장된 데이터는 시스템이 켜지고 동작하기 위한 가장 기본적인 코드이기 때문에, 단 1비트의 오류도 부팅 실패, 펌웨어 손상, 제어 오류로 이어질 수 있다. 즉 SPI NOR Flash는 용량은 크지 않지만, 시스템 신뢰성 측면에서는 매우 중요한 저장장치이다.

**하지만 상용 SPI NOR Flash는 내부 상태 관측성이 낮다. NAND Flash 연구에서 다루는 Vth 분포, read reference voltage, cell 상태 변화 같은 내부 물리량을 외부 사용자가 직접 확인하기 어렵다. 외부 인터페이스에서 얻을 수 있는 정보는 대부분 “정상적으로 읽히는가 / 읽히지 않는가”에 가까운 결과뿐이다.**

이 점이 문제다. Flash가 현재 정상적으로 읽힌다고 해서 내부 데이터 무결성 마진이 충분히 남아 있다는 뜻은 아니다. P/E 반복, 온도 변화, 전압 변화, 보드 노화, 인터페이스 열화가 누적되면 읽기 마진은 점차 줄어들 수 있지만, 일반적인 PASS/FAIL 검증은 그 마진이 얼마나 줄어들었는지를 보여주지 못한다.

따라서 SPI NOR Flash처럼 내부를 직접 들여다보기 어려우면서도 부트/펌웨어 저장이라는 높은 중요도를 가지는 메모리에는, 고장 발생 후 불량을 판정하는 방식이 아니라 고장 전 단계에서 데이터 무결성 마진을 외부에서 정량적으로 계측하는 방법이 필요하다. 본 과제는 FPGA 기반 위상 스윕을 통해 SPI Flash 외부 인터페이스에서 관측 가능한 타이밍 마진 폭을 측정하고, 이를 Flash 열화 상태와 수명 위험도 추정 지표로 활용하고자 한다.

💡**즉 우리는 Flash cell 내부를 직접 들여다보는 대신, 샘플링 위상,  SPI Clock, BER, 유효 윈도우 폭, erase/program 시간, ECC corrected count, Fail map, 온도 같은 외부 관측값을 이용해 데이터 무결성 마진을 측정한다.** 

| 구분 | 선행연구 | 우리 프로젝트 |
| --- | --- | --- |
| 대상 | 주로 3D NAND, TLC/QLC, SSD | 상용 SPI NOR Flash 중심 |
| 관측값 | Vth distribution, read reference voltage, fail bit, RBER | timing bathtub width, BER, P/E latency, ECC count |
| 장비 | raw NAND tester, 제조사급 계측, SSD 내부 로그 | FPGA/Zybo 기반 계측 플랫폼 |
| 목표 | 수명 예측, read voltage 최적화, SSD failure prediction | 외부 관측 가능 마진 지표 추출 및 열화 추정 |
| 결과 | error rate, lifetime, optimal read/erase parameter | ps 단위 유효 윈도우 폭, margin trajectory, wear index |
| 창의성 | 내부 물리량 분석 | 내부 물리량을 직접 못 보는 제약을 FPGA 계측으로 우회 |

## 1. Vth 분포 기반 Flash 신뢰성/수명 평가

Research on 3D TLC NAND Flash Reliability from the Perspective of Threshold Voltage Distribution

이 논문은 3D TLC NAND Flash의 신뢰성과 수명을 **threshold voltage distribution**, 즉 문턱전압 분포 관점에서 평가한다. 특히 P/E cycle이 증가할수록 Vth 분포가 이동하고 퍼지며, 이 변화가 read margin 감소와 bit error 증가로 이어진다는 점을 다룬다. 검색 결과에 따르면 해당 연구는 Xilinx Zynq-7000을 주제어로 하는 실험 플랫폼을 사용했다는 점도 우리 프로젝트와 연결성이 있다.

- **Vth, 문턱전압**: Flash cell이 0인지 1인지, 또는 TLC/QLC에서 어떤 state인지 구분하는 기준 전압.
- **Vth distribution**: 수많은 cell들의 문턱전압이 어느 범위에 퍼져 있는지 나타낸 분포.
- **Read margin**: 인접한 state 사이가 얼마나 떨어져 있는지 나타내는 여유 폭.
- **P/E cycle**: Program/Erase 반복 횟수. Flash가 마모되는 핵심 원인.

💡 **우리 프로젝트와의 연결**

선행연구는 내부 Vth 분포를 직접 측정해서 Flash 수명을 예측한다. 우리는 상용 SPI Flash에서 내부 Vth 분포를 직접 볼 수 없으므로, FPGA의 위상 스윕으로 **외부에서 관측 가능한 타이밍 마진 폭**을 측정한다.

선행연구:
Vth 분포 변화 → read margin 감소 → error 증가 → 수명 예측

우리 프로젝트:
샘플링 타이밍 마진 폭 감소 → 데이터 무결성 경계 축소 → 열화 상태 추정

💡 **보고서용 포인트**

> 기존 연구가 Flash 내부 Vth 분포를 이용해 수명을 평가했다면, 본 과제는 상용 SPI Flash 환경에서 직접 접근 가능한 timing margin width를 외부 관측 가능 마진 지표로 사용한다.
> 

## 2. 고효율 Vth 분포 측정 방법

A High-Efficiency Threshold Voltage Distribution Test Method Based on the Reliability of 3D NAND Flash Memory

이 연구는 3D NAND Flash의 Vth 분포를 더 효율적으로 측정하는 방법을 제안한다. 검색 결과에 따르면 read offset 기능을 활용해 read reference voltage를 조절하고, 이를 통해 3D TLC Flash의 threshold voltage distribution과 programming interference를 분석한다. 또한 Zynq-7000 기반 플랫폼을 사용한 것으로 정리되어 있다.

- **Read offset**: 읽기 기준 전압을 조금씩 바꾸어 cell state 경계를 탐색하는 방법.
- **Read reference voltage**: cell을 읽을 때 0/1 또는 여러 state를 구분하는 기준 전압.
- **Programming interference**: 한 cell에 데이터를 쓸 때 주변 cell의 전기적 상태에 영향을 주는 현상.

💡 **우리 프로젝트와의 연결**

이 논문의 핵심은 “단순 PASS/FAIL이 아니라, 마진을 직접 계측한다”는 점이다. 우리도 같은 철학을 가진다. 다만 우리는 read voltage를 직접 스윕하는 대신, FPGA 샘플링 위상을 스윕한다.

💡 **차이점**

우리는 NAND 전용 내부 명령이나 제조사급 장비 없이, SPI Flash의 외부 인터페이스에서 측정 가능한 **타이밍 욕조 곡선**을 만든다.

## 3. FPGA 기반 NAND Flash 신뢰성 테스트 플랫폼

## FPGA-based Reliability Testing and Analysis for 3D NAND Flash Memory

이 논문은 3D NAND Flash 신뢰성 평가를 위해 FPGA 기반 하드웨어/소프트웨어 협업 실험 플랫폼을 설계한 연구다. 논문 초록에 따르면 이 플랫폼은 NAND Flash의 timing control과 error feature extraction을 구현하고, LabVIEW 기반 PC 소프트웨어로 실험 데이터를 빠르고 안정적으로 처리한다.

- **Timing control**: Flash에 명령을 보내고 데이터를 읽는 타이밍을 제어하는 것.
- **Error feature extraction**: 오류 개수, 오류 위치, 오류 유형 등 신뢰성 분석에 필요한 특징값을 뽑는 것.
- **FPGA-based tester**: FPGA를 단순 제어기가 아니라 반복 실험용 계측 장비로 사용하는 방식.

💡 **우리 프로젝트와의 연결**

이 논문은 FPGA가 Flash 신뢰성 실험 장비로 적합하다는 근거가 된다.

선행연구:
FPGA + PC 소프트웨어로 NAND 신뢰성 지표 수집

우리 프로젝트:
FPGA + PS/Host로 SPI Flash timing margin, BER, 윈도우 폭 수집

💡 **우리의 차별점**

선행연구가 raw NAND 신뢰성 분석 플랫폼에 가깝다면, 우리는 상용 SPI Flash를 대상으로 **ps 단위 sampling phase sweep**을 수행해 유효 윈도우 폭을 측정한다. 즉 FPGA를 단순한 Flash controller가 아니라 **마진 계측기**로 쓴다

## 4. 온도와 P/E interval이 NAND 신뢰성에 미치는 영향

## Impact of Program–Erase Operation Intervals at Different Temperatures on 3D Charge-Trapping TLC NAND Flash Memory Reliability

이 2024년 Micromachines 논문은 3D CT TLC NAND Flash에서 Program과 Erase 사이의 interval, 동작 온도, P/E cycle이 신뢰성에 미치는 영향을 분석한다. 연구는 25°C와 85°C 조건, fresh state와 10K P/E cycling state에서 실험을 수행했고, 온도와 P/E interval이 fail bit count와 error mode에 영향을 준다고 보고한다.

- **CT NAND**: Charge-Trapping NAND. 전하를 trap layer에 저장하는 NAND 구조.
- **TLC**: 한 cell에 3비트를 저장하는 구조.
- **FBC, Fail Bit Count**: 실패한 bit의 개수.
- **Program disturb / Read disturb / Data retention**: 쓰기, 읽기, 보존 과정에서 생기는 대표적인 Flash 신뢰성 문제.

💡 **우리 프로젝트와의 연결**

이 논문은 온도 조건이 Flash 신뢰성 실험에서 단순 부가 조건이 아니라 핵심 변수라는 근거가 된다.

선행연구:
온도 + P/E interval + P/E cycle → fail bit count와 error mode 변화

우리 프로젝트:
온도 + P/E stress → timing margin width와 error count 변화 측정

💡 **보고서용 포인트**

> 온도와 P/E 조건은 Flash reliability를 변화시키는 핵심 실험 축이다. 본 과제는 이를 SPI Flash margin bench에 반영하여 온도 조건별 타이밍 마진 변화를 비교한다
> 

## 5. NOR Flash read disturb와 온도 영향

## Read Disturb on Flash Memories: Study on Temperature Annealing Effect

이 연구는 자동차용 embedded Flash를 대상으로 read disturb를 분석한 논문이다. 논문 설명에 따르면 NOR 구조에서는 하나의 cell을 읽을 때 같은 word line의 cell들이 함께 bias되어 read disturb가 문제가 될 수 있으며, 반복 읽기 동작은 threshold shift를 유발할 수 있다. 또한 automotive application을 대상으로 한다는 점에서, 가혹한 환경에서 Flash 신뢰성이 중요하다는 배경 근거로 사용할 수 있다.

```
          Bit line
            ↓
```

Word line 0 ── [셀] [셀] [셀] [셀]
Word line 1 ── [셀] [셀] [셀] [셀]
Word line 2 ── [셀] [셀] [셀] [셀]

💡word line은 여러 셀의 gate를 한 줄로 연결한 전선이다. 특정 셀 하나를 읽으려면 해당 셀이 연결된 word line에 읽기 전압을 걸어야 한다. 그런데 word line은 여러 셀이 공유하기 때문에 선택한 셀뿐 아니라 같은 word line에 있는 다른 셀의 gate에도 전압이 걸린다. 즉 gate 쪽에는 반복적인 전기적 스트레스가 들어갈 수 있다. 즉 반복해서 읽는 동작 자체가 주변 셀의 저장 상태를 조금씩 변화시키기 때문에 셀이 판정 경계에 점점 가까워지고 이에 잘못 판정 될 수 있는 것이다. 

- **Read disturb**: 반복 읽기 때문에 읽지 않은 cell의 전하 상태가 변하는 현상.
- **Threshold shift**: 문턱전압이 원래 위치에서 이동하는 것.
- **Automotive embedded Flash**: 차량용 MCU 내부 코드 저장용 Flash.

💡 **우리 프로젝트와의 연결**

NOR Flash는 신뢰성이 높다고 알려져 있지만, 차량용/임베디드 환경에서는 반복 읽기, 온도, P/E stress에 따른 마진 감소 문제가 중요하다.

선행연구:
반복 read + 온도/annealing 조건 → threshold shift와 read disturb 분석

우리 프로젝트:
반복 read/P-E 이후 timing margin width 변화 측정

💡 **보고서용 포인트**

> SPI NOR Flash는 접근성이 높고 신뢰성이 좋은 메모리지만, 임베디드/차량용 환경에서는 작은 마진 감소도 시스템 안정성 문제로 이어질 수 있다. 따라서 정상/불량 판정보다 사전 마진 계측이 중요하다.
