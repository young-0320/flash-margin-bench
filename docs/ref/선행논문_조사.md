# 선행논문 조사

NOR 는 NAND보다 임베디드나 차량용 반도체 신뢰성 분야에 집중된 편, 가혹한 환경에서도 버티는 내구성 검증 연구가 주를 이룬다.

- 온도 변화에 따른 Vth 와 에러율
    
    ## NAND Flash Cell의  온도  보상  회로  연구  및  분석
    
    [https://www.dbpia.co.kr/pdf/pdfAiChatView.do?nodeId=NODE11890506&width=1158](https://www.dbpia.co.kr/pdf/pdfAiChatView.do?nodeId=NODE11890506&width=1158)
    
    - Cell의 Vth에 따라 state가 존자해며 각 state에 맞는 읽기 전압을 정확하게 인가해 state 구분한다.
    - NAND Flash Cell의 Vth는 온도가 증가할 수록 낮아지는 특성이 존재하므로 동일한 state에서도 온도에 따라 읽기 전압을 변경해주어야 온도 변화에 무관하게 cell에 저장된 Data를 정확하게 읽을 수 있다.

- 스트레스 테스트
    
    ## 메모리 컨트롤러 무결성 검증을 위한 FPGA 테스트로직 설계 및 구현
    
    [https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE11669894](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE11669894)
    
    - 쓰기 패턴을 조작해 테스트 시간을 단축하는데 집중한 연구
    - 칩의 수명을 닳게 만드는 테스트가 오래 걸리는 문제를 해결하기 위해 칩이 빠르게 지치게 하기 위해서 Cell to Cell interference 를 의도적으로 극대화
    
    - EORAS (짝수/홀수 행 어드레스 시퀀스) : 짝수 줄과 홀수 줄을 지그재그로 번갈아 가며 데이터를 넣어 주변 메모리 셀들의 전압을 강제로 흔든다.
    - 의사(Quasi)-랜덤 데이터: 무작위 데이터보다 인접한 셀끼리 전기적 간섭을 더 심하게 일으키도록 수학적으로 조작된 특수한 데이터 패턴을 주입한다.
    
    이러한 방법들은 데이터 저장 공간이 아파트처럼 붙어있는 NAND Flash라 셀 간 간섭이 엄청나서 가능하다.

    💡
    
    0~7번 뱅크 순차적 P/E 반복을 유지하되 위 논문과 같은 방법론 적용
    
    **ex) 체커보드 패턴**
    
    0과 1이 반복되는 데이터를 쓰게 되면 셀과 셀 사이의 전압 차이가 커져 빠르게 Cell에게 스트레스 줄 수 있음

- NOR Flash Read Disturb
    
    ## **Read Disturb에 의한 Triple-Level Cell Split-Gate NOR Flash의 신뢰성 저하 분석 및 모델링**
    
    https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE12036529
    
    - **Read Disturb :** 반복적인 읽기 동작으로 인해 플래시 메모리 셀의 데이터가 손상되거나 성능이 저하되는 현상
    - **On-current :** MOSFET가 켜졌을 때 드레인-소스 간에 흐르는 전류를 의미하며 메모리 셀의 읽기 성능을 나타냄
    - **TLC (Triple-Level Cell) :** 하나의 메모리 셀에 3비트의 데이터를 저장하는 기술
    
    셀의 문턱 전압이 의도치 않게 증가하는 soft program이나 감소하는 soft erase 현상을 유발한다.
    
    read disturb 횟수가 증가함에 따라 on-current가 감소하는 현상이 나타난다. 
    
    읽기 전압인 Vread 값에 가까울수록 전류 저하가 더 크게 나타난다.
    
    - **NOR Flash**
        
        셀이 병렬로 구성되어 불량 섹터에 대한 안정성 제공하며 데이터 읽기 시 랜덤 액세스가 가능하고 빠른 읽기 속도를 구현할 수 있는 장점을 지닌다.
        
        TLC 같이 셀 당 비트 밀도가 높은 플래시 메모리 셀에 대한 수요 증가
        
        **셀의 밀도가 높아질수록 신뢰성이 중요**해진다. 높은 비트 밀도를 가진 플래시 메모리 소자의 신뢰성을 확보하기 위해서는 read disturb와 같은 현상에 대한 연구가 필요하다.
        
        → FG가 작아지면서 FG에 들어갈 수 있는 전자의 수도 줄어든다.
        
        → 열화나 스트레스로 인해 산화막을 뚫고 새어나가는 전자의 영향이 커지며 Vth가 급격하
             게 감소해 데이터가 뒤집힌다.
        
        → 자동차의 ECU 제어 코드, 마이크로컨트롤러의 펌웨어를 저장해 1비트만 에러가 나도 명      령어 체계가 무너지며 전체 시스템 죽는다.
        
    
    <aside>
    💡
    
    **타이밍 마진을 재려는 연구 배경**
    
    칩의 밀도가 높을수록 다양한 요인에 의해서 마진은 더 빠르게 줄어든다.
    
    </aside>
    
- NOR Flash 데이터 복구
    
    ## **순환 중복 검사를 이용한 SPI-NOR flash의 데이터 복구 방법에 대한 연구**
    
    https://www.dbpia.co.kr/journal/detail?nodeId=T15668125
    
    - NOR Flash는 신뢰성이 높다고 알려져 있으나 IoT 및 임베디드 기기의 가혹한 동작 환경에서 데이터 오염으로 인한 시스템 결함이 지속적으로 보고
    - 에러를 발견했을 때 2.5MB 전체를 지우고 다시 쓰면 시간이 너무 오래 걸리니까 데이터를 블록 단위로 쪼개서 에러가 난 블록만 골라서 다시 쓰는 기법 사용
