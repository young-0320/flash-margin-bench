## 1. Sakib 외 2018 — 가장 가까운 연구

`the existing works on counterfeit IC detections are mostly on FPGA, SRAM, DRAM etc. and there are a very few works on the detection of recycled Flash memory"`

즉 재활용 플래시 판별 연구 자체가 드물다는 걸 선행 연구 저자가 직접 말했다.

**한 일.** 재활용(중고) 플래시를 **사전 데이터베이스 없이** 판별한다. 블록 100개의 소거 시간 · 페이지 프로그램 시간 · 실패 비트 수(FBC)를 수십-2,700
사이클에 걸쳐 재서, **소거 시간이 가장 좋은 지표**라고 결론냈다. 칩은 raw NAND(Micron SLC 34nm · 25nm, MLC 20nm, Toshiba SLC 32nm) — NAND
소켓과 ARM Cortex-M3 보드. 수명의 **0.05-3%** 사용을 확신도 98% 이상으로 검출.

**「데이터베이스 없이」 가 되는 이유.** 판정 기준이 **데이터시트의 신품 중앙값**이다. 두 전제에 기댄다.

1. 같은 품번이면 **신품 소거 시간 분포가 매우 좁다** — 「데이터시트 중앙값이 그 품번의 신품 값을 잘 대표한다」(5.3절 (1)). 근거는 같은 품번 칩 **3개**
2. 조금만 써도 소거 시간이 **계단식으로 크게**(약 1ms) 뛰어, 신품 분포와 겹치지 않는다

판정: 칩의 블록 소거 시간 CDF 와 신품 CDF 가 겹치는 정도(α)로 **확신도 = (1 − α) × 100%**. 답은 「재활용 / 정품」 **이진**이다.

**우리에게 주는 것**

- **계단의 해석**: 「소거는 펄스와 검증의 반복이라 펄스가 하나 늘 때마다 계단식으로 는다」(5.2절, 펄스 폭 약 1ms) — 우리 빠른 무리의 계단을 칩 내부
  알고리즘으로 읽는 근거. 다만 우리 계단 높이(약 21ms)는 펄스 하나(약 1ms)보다 훨씬 커서, 같은 기전이라도 단위가 다르다(5번 논문 참고)
- 「소거 시간이 최적 지표」 라는 판단의 선례 — 우리 결론(타이밍 창은 안 변하고 소거 시간이 변한다)과 같은 방향

**우리와 다른 점 — 차별화**

|           | Sakib 2018                                   | 우리                                                     |
| --------- | -------------------------------------------- | -------------------------------------------------------- |
| 칩        | NAND                                         | **SPI NOR** (W25Q64FV 단품)                        |
| 답        | 썼다 / 안 썼다 + 확신도                      | **몇 번 썼나** + 68 · 95% 구간 + 등급             |
| 범위      | 초기 사용(수명 0.05-3%)                      | 0 → 100k (정격 전체)                                    |
| 신품 기준 | 데이터시트 중앙값 (칩 간 차이가 작다는 전제) | **칩 자신의 안 닳은 섹터**(32-127) — 칩 안 정규화 |
| 검증      | 신품 분포와 겹침                             | **블라인드 · LOCO · 합성 복원**                  |

- **전제가 우리 칩에서 깨진다.** 같은 품번 W25Q64FV 신품 15개의 소거 중앙값이 **26-51ms(2배)** 이고, 이 차이가 생산 시기(날짜 코드
  1423 이전 · 1430 이후)로 갈린다(`../chip_registry.md` 마킹 절). 데이터시트 대표값을 신품 기준으로 쓰면 빠른 무리 칩은 수만 회를 써도
  「신품」 으로 보인다 — **가장 강한 차별점**
- **보완 관계도 정직하게.** 그들 방법은 데이터시트와 비교하므로 **칩 전체를 고르게 쓴 재활용 칩**도 잡는다. 우리 정규화는 안 닳은 섹터가 남아
  있어야 작동해, 전체를 고르게 쓴 칩에는 약하다

**기준선 ① 구현 지침 (대본 7장).** 허수아비가 아니라 **이 방법 그대로** — 신품 기준은 데이터시트 값(W25Q64FV Rev L 의 4KB 섹터 소거 typ — **끝자리 IG 60ms · IQ/IF 45ms**, 우리 칩은 SIG · SIQ 가 섞여 있고 전부 typ 보다 빠르다) 또는 신품 칩 분포,
판정은 마모 섹터 소거 시간 분포와 신품 분포의 겹침 α, 확신도 1 − α. 우리 82점(LOCO 와 같은 점)과 각 칩의 신품 측정에 적용해 검출률 · 오경보를 낸다.
몇 번 썼는지는 답하지 못한다는 것을 표에 그대로 적는다.

**발표 · 원고 문장 (원문 근거).**

> 선행 연구(NAND, 2018)는 소거 시간으로 「썼는지」 를 가린다. 같은 품번이면 신품 소거 시간이 거의 같다는 전제로 데이터시트 값을 기준으로 쓴다.
> 같은 품번 SPI NOR 신품 15개는 26ms 에서 51ms 까지 두 배 차이가 났다 — 이 칩에서는 그 전제가 성립하지 않고, 답도 「썼다/안 썼다」 뿐이다.

## 5. LIU 외 2019 — NOR 섹터 소거가 왜 느려지나

**한 일.** SMIC 65nm NOR 공정으로 **128Mb SPI NOR 칩**을 직접 설계 · 제작해, 섹터 소거 시간이 P/E 에 따라 느려지는 기전을 분석하고 줄이는 방법을
제안 · 검증했다. 칩 수준 소거 열화 연구가 드물다는 것이 출발점이다.

**섹터 소거의 내부 4단계** (1.1절) — 겉에서 재는 소거 시간은 이 넷의 합이다.

> T_total = T_ppgm + T_erase + T_oec + T_recover

| 단계                                 | 하는 일                                                                                                | P/E 에 따라 늘어나는 이유 (1.2절)                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| **T_ppgm 사전 프로그램**       | 지울 섹터의 모든 셀을 먼저 「프로그램 상태」 로 맞춰 출발점을 통일                                     | 드레인 근처 산화막에 갇힌 전하가 열전자 주입(CHE)을 막아**프로그램 효율이 떨어짐**                 |
| **T_erase 일괄 소거**          | FN 터널링으로 섹터 전체를 지움                                                                         | 채널 쪽 음전하 트랩이 쌓여**FN 소거가 느려짐** · 계면 결함으로 읽기 전류가 줄어 더 깊이 지워야 함 |
| **T_oec 과소거 교정**          | 너무 깊이 지워진(과소거) 셀을 찾아 고치고, 약하게 다시 써서 분포를 좁힘                                | 구멍(정공) 트랩으로**이상하게 빨리 지워지는 셀(erratic cell)** 이 늘어 교정할 셀이 많아짐          |
| **T_recover 비선택 섹터 복구** | 같은 물리 블록의**다른 섹터**를 읽어 보고, 간섭으로 문턱이 떨어진 셀을 다시 씀 (한 번에 8/16 셀) | 산화막 트랩으로**누설(SILC)이 커져** 간섭받는 셀이 늘어남                                          |

- **같은 물리 블록의 간섭**: 면적을 줄이려 여러 섹터를 **한 P-웰**에 두고 비트라인 · 소스라인을 공유한다. 한 섹터를 지울 때 같은 물리 블록의 다른
  섹터에도 고전압이 걸려 **드레인 간섭 · 웰(기판) 간섭**이 생긴다
- **셀 수준**: 10만 사이클 뒤 메모리 창이 5.3V → 2.9V 로 줄었다(65nm ETOX, 터널 산화막 약 9nm)
- **칩 수준 결과**: 두 모드 모두 초기 섹터 소거 **30ms 이내**. 기존 방식은 **3만 사이클 뒤 100ms 이상, 10만 뒤 200ms 이상**, 최적화 방식(계단형 펄스 +
  비선택 섹터 워드라인 플로팅)은 10만 뒤 **104.9ms**

**우리 관찰과의 대응 — 모두 가설이다 (확인하지 않았다)**

| 우리 관찰                                                                                                        | 이 논문으로 읽으면                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 소거 시간이 P/E 에 따라 는다 (빠른 무리 100k 에 2.8-4배 · 느린 무리 1.6-1.75배)                                 | 4단계가 모두 늘어나는 구조. 10만 뒤 크기(우리 체크포인트 소거 p50 73-120ms)는 이 논문의 최적화 칩(104.9ms)과 같은 자릿수                                                                                                                     |
| **빠른 무리의 계단 (높이 약 21ms, 칩이 바뀌어도 일정, 사이 0%)**                                           | 내부 알고리즘이**단계나 반복(교정 · 복구 루프)을 하나 더 쓰기 시작한 순간**. 계단 단위가 일정한 것은 알고리즘의 고정된 반복 단위를 시사. Sakib 의 「펄스 하나 = 약 1ms 계단」 보다 커서, 펄스 하나보다 큰 단위(단계 · 루프)일 가능성 |
| **128KB 소거 교란** (근접 대조군 7-13 이 100k 뒤 1.06-1.15배, 블록 2 에서 약 1.00 으로 끊김, 다섯 칩 재현) | **같은 물리 블록(공유 P-웰)의 비선택 섹터가 매 소거마다 웰 · 드레인 간섭을 받는다** — 그 섹터의 산화막도 조금씩 닳는다. 경계가 128KB 로 날카로운 것은 W25Q64FV 의 **물리 블록(P-웰) 단위가 128KB** 라는 뜻일 수 있다           |
| **느린 무리만 프로그램 시간이 오른다** (+21-26%, chip07 2.1배)                                             | 드레인 근처 트랩으로**CHE 프로그램 효율이 떨어지는** 기전 — 왜 느린 무리에서만인지는 설명하지 못한다                                                                                                                                  |
| **두 무리가 생산 시기(2014년 중반)로 갈린다**                                                              | 이 논문은**같은 셀이라도 소거 알고리즘 · 바이어스 조건에 따라 초기 속도와 열화 모양이 크게 달라진다**를 보였다. 2014년 중반의 내부 알고리즘 · 트림 변경이 두 무리를 만들었을 가능성 — 확인할 방법은 제조사 자료뿐이다               |

**쓰는 곳**

- 졸업논문의 토론 절 · 학회 원고의 「물리 해석」: 계단 · 128KB 교란 · 두 무리를 내부 알고리즘과 산화막 열화로 설명하는 근거
- 128KB 경계가 물리 블록 단위인지는 W25Q64FV 데이터시트의 블록 구조(64KB 블록 · 보호 단위)와 대조해 볼 것
